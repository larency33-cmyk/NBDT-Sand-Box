# NBDT Hub v0.6.124 — обновлённая страница Project overview

## Что изменено
- Переработано только фактически используемое окно **Overview** по утверждённому макету: заголовок Project overview, рабочие разделы и визуальная иерархия.
- **Base Configuration, Ready for Deployment, Deployed, Cyber Approved**: сохранены исходные расчёты Configuration Report и анимации пяти оттенков жидкости (передний и задний слои волн, пузырьки), но карточки и внешний вид жидкостных кругов адаптированы под макет. Толстое внешнее кольцо прогресса скрыто стилистически; анимационный компонент не заменён изображением.
- **Needs attention**: одна широкая карточка с Issues (реальные открытые проблемы по приоритету) и Configuration remaining (реальные незавершённые системы, нужный этап, прогресс и число оставшихся устройств). Строки ведут в рабочие разделы.
- **This week**: динамическое `done / total`, процент выполненного, компактная матрица статусов (до 27 пропорциональных ячеек) и реальные milestone-события; сохранён переход в Weekly Tracker.
- **System readiness**: таблица с окрашенными ячейками Base / Ready / Deployed, рассчитанными из сохранённых счётчиков Configuration Report. Отсутствие числовой базы показано знаком «—», а не выдуманным нулём.
- **Recorded activity**: компактная вертикальная лента из настоящего activityLog с прежним окном History.
- **Lessons learned**: отдельное zero-state оформление при отсутствии записей и информативная карточка при наличии записей, с реальными подтверждениями текущего проекта и рабочими переходами в Systems.
- Адаптивность для ноутбуков, планшетов и узких экранов. Изменения CSS ограничены классом `nb124-overview`.

## Что сохранено
- Оригинальная анимация волн v0.6.70–0.6.71, значения KPI и модель данных.
- Роуты `roadmap`, `issues`, `config-report`, `systems` и переход к конкретной системе через Open Guide.
- Хранение данных, авторизация, назначения, System Registry и остальные страницы сайта.

## Важно
- Значения на изображении (88%, 26/27 и т. п.) **не прописывались в проект**. Данные отображаются на основе выбранного проекта.
- Полную production-сборку не удалось проверить: npm/Vite недоступны в этой среде. Chromium не завершил запуск статической проверки, поэтому реальный внешний вид в работающем браузере не подтверждён.
