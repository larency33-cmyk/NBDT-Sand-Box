# NBDT Hub v0.6.86 — Owner на каждой карточке System Registry

## Новое

- Строка с иконкой человека **Owner** теперь всегда отображается на каждой карточке System Registry, даже если владелец ещё не назначен.
- Если назначений нет, написано **Not assigned**. Если есть, показывается имя владельца. Сохранённые совместные назначения продолжают отображаться списком имён.
- Для **Admin** и **Super Admin** строка Owner — компактный выпадающий список, содержащий **только сотрудников из Assignment**. **Guest** видит текст без возможности изменения.
- Выбор сотрудника обновляет основное хранилище **Assignment**. Это автоматически отражается в System Registry, фильтре All owners, Assignment и связанных сводках.
- Выбор **Not assigned** удаляет Assignment-записи только указанной системы.
- Если у системы было несколько владельцев, выбор одного человека делает его единственным владельцем этой системы; прочие системы не затрагиваются.
- При сохранении обновления блокируется повторное изменение Owner и показывается ошибка, если сохранение не удалось.
- Экспорт System Registry использует те же значения Owner из Assignment, включая Not assigned.

## Что важно

- Никакого массового переназначения систем при установке новой версии нет.
- Изменяется только выбранная через карточку система. Для систем с одинаковым названием в разных проектах применяется существующее правило: Assignment хранит назначения по **названию**, поэтому они будут иметь общего владельца.
- Никакие старые поля assigneeId на системных карточках не используются для записи владельца.
- Остальная логика, включая Guide, Issues, календарь, чек-листы и импорт Excel, не изменена.

## Проверка

1. Открыть System Registry с несколькими системами и убедиться, что **Owner: Not assigned** есть на ранее пустых карточках.
2. В Admin/Super Admin нажать поле Owner, назначить человека и проверить имя и фильтр All owners.
3. Перейти в Assignment: у сотрудника должна появиться соответствующая система.
4. Сменить Owner, проверить что запись переместилась. Затем выбрать Not assigned и проверить снятие назначения.
5. Проверить shared-назначение (два сотрудника): после выбора одного остаётся только он.
6. В Guest проверить, что список изменить нельзя.
7. Перезагрузить сайт и убедиться, что данные остались.
