# NBDT Hub v0.6.111 — правильный Description при импорте из Excel

## Исправлено

При вставке из Excel шаблона конфигурации третья строка `Hardware deployment and configuration required` — служебный заголовок. Его **никогда** нельзя импортировать как описание системы.

- Description теперь берётся из первой содержательной ячейки/строки **непосредственно под этим заголовком**. Для Mobile Telehealth это полный абзац о медицинской платформе, а не текст «Hardware deployment … required».
- Заголовок распознаётся даже при добавлении иконок, декоративных символов, пробелов и при вариантах с `&` или без `and`. Метка `DOCS`, если она склеилась с заголовком, игнорируется.
- Работает с обычным Excel TSV и `text/html` копированием, в том числе с объединёнными ячейками и ситуацией, когда заголовок и абзац находятся в одном HTML-элементе.
- Сохраняет целиком многострочное описание. Если настоящего описания нет, система не подменяет его служебным заголовком.
- При повторном импорте корректное Description заменяет ошибочно импортированную строку в сохранённой системе. Прочие поля, чек-листы и Lessons Learned не затрагиваются.
- Без изменений остались предпросмотр, явное подтверждение импорта, административные права и другие страницы.
