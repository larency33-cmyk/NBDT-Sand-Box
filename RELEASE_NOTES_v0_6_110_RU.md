# NBDT Hub v0.6.110 — исправление Search и иконок статусов

Основа: v0.6.109.

- **System Registry → Search systems:** синяя рамка теперь непрерывная по всему периметру (включая верхний и нижний края). Корень проблемы: вложенный input получал непрозрачный белый фон от общего правила приложения и перекрывал границу родительского поля. Фон input исправлен на прозрачный с ограничением размеров. Focus-подсветка сохранена.
- **All statuses → Completed:** зелёный заполненный круг с белой галочкой, без лишней цветной подложки.
- **All statuses → In progress:** синее разомкнутое кольцо без точки и фонового бейджа.
- **All statuses → Not started:** тонкая серая окружность без заливки и фонового бейджа.
- Стили ограничены полем поиска и меню All statuses. Иконки Device Type, Platform, Connection и Owner, карточки и фильтрация оставлены как в v0.6.109.
- Данные проекта не изменяются, миграция не требуется.

Исходный код и тесты валидированы, подробности в `VALIDATION_v0_6_110.md`. Полная production-сборка и реальный boot приложения — только при доступных npm-зависимостях.
