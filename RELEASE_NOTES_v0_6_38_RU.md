# NBDT v0.6.38 — System Registry: фильтр Device Type и данные из Guide

Основа: **v0.6.37**. Обновления касаются System Registry и его активного редактора профиля; данные пользователей не обнуляются.

## Изменения

1. Снята декоративная полоса из 7 больших круглых иконок над карточками.
2. Добавлен интерактивный фильтр **Device Type** в общую панель фильтров (вместе с поиском, Platform, Connections, Owners). Внутри раскрытого списка показаны иконки и названия семи типов: **Phone, Tablet, PC, Laptop, Kiosk, POS, App only**. Предусмотрены All device types, подсветка выбора, закрытие по Escape/клику вне списка, сброс по Clear filters.
3. В самих карточках сохранены круглые цветные иконки по типу устройства; назначение устройства вычисляется из сохранённой категории и при необходимости из названия/модели старых демонстрационных систем.
4. Технические характеристики **Device model, OS, Connection, Naming** берутся из **того же источника, что Technical essentials в Configuration Guide**: из опубликованного `publishedGuide.technicalSnapshot`; если его нет — из текущих технических полей primary-профиля системы. Строки поиска, Platform, Connection и CSV Export используют те же видимые данные.
5. Убраны старые вспомогательные селекты `to_confirm / confirmed / example / N/A` после каждого поля и отдельная настройка `Technical value state`. Надпись `To confirm · legacy source` скрыта в активном Guide. **Существующие значения `valueStates` из сохранённых записей не удаляются.**
6. Сохранены кнопки Open guide и Documentation, редактор системы, поле Description, остальные данные и функции.

## Важно

Если опубликованный Guide содержит снимок характеристик, карточка будет показывать именно опубликованную версию. Чтобы обновить карточку после редактирования профильных полей, опубликуйте новую версию Guide. При отсутствии опубликованного снимка обновление редактора отражается на карточке сразу после сохранения.

**Контроль:** 232 автоматических теста пройдены; TSX синтаксис новых файлов проверен через TypeScript transpilation. Production-сборку в этой среде провести не удалось: пакетный менеджер не смог загрузить зависимости из npm.

## Остальные разделы

Weekly Tracker, Issue Tracker, Configuration Report и локальное хранилище проекта не менялись.
