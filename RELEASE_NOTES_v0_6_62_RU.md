# NBDT v0.6.62 — Overview Visual Refinement

**Базовая версия:** v0.6.61. **Дата:** 30 октября 2026.

## Цель

Сделать Overview визуально полноценным центром управления, не перегружая страницу и не дублируя отчётные показатели. Сохранить существующие источники данных и рабочие переходы.

## Изменения UI

- **Только область Overview.** Боковое меню, авторизация, прочие страницы и общие стили не менялись.
- **Верхний заголовок:** выровнена типографика, спокойный голубой фон, более аккуратные дата и кнопка текущей проектной недели.
- **Четыре KPI:** улучшены размеры, иерархия текста, кольцевые показатели, отступы и тонкие линии прогресса. Цвет закреплён за исходной метрикой, без дополнительных условных процентов.
- **Systems requiring attention:** визуально главный рабочий блок. Тонкая тёплая линия слева, более разборчивая таблица, акцент на серьёзности проблемы без заливки всего блока красным.
- **This week:** компактные статусы задач, читаемые Milestones, мягкие цветовые категории и нейтральные действия перехода.
- **System readiness:** улучшенная табличная иерархия, читаемые столбцы Qty / Base / Ready / Deployed.
- **Recorded activity / Ownership coverage:** более сдержанная вторичная визуальная роль при достаточном контрасте.
- **Интерактивные состояния:** аккуратные hover, keyboard focus-visible, reduced motion; адаптация на ширинах 1320, 1150, 760 и 460 px.

## Данные и логика без изменений

- KPI продолжают получать ровно те же значения из `reportCounts`, что и Configuration Report.
- Проблемы, задачи, Milestones и Owners остаются привязаны к Issue Tracker, Weekly Tracker и Assignment.
- Никаких выдуманных данных, новых статусов, иллюстративных процентов роста или общего процента готовности проекта.
- Автоматическое обновление при изменениях данных сохранено; логика пересчёта и маршрутизации не переписывалась.
- IndexedDB, доступы Guest/Admin/Super Admin и работа остальных страниц сохранены.

## Качество и ограничения

- **353/353** тестов прошли (349 предыдущих и 4 новых UI-regression).
- `scripts/check-symbols.cjs` и `scripts/check-syntax.cjs` пройдены.
- `tinycss2`: stylesheet разбирается без ошибок.
- Полноценная `vite build` и браузерный smoke-test рабочего приложения **не подтверждены локально**: отсутствуют npm-зависимости. GitHub release gate должен выполнить сборку и проверку маршрутов до деплоя.

## Установка

1. Для обновления GitHub используйте `NBDT_GitHub_Changed_Files_v0_6_62.zip`, сохранив относительные пути файлов и заменив совпадающие файлы.
2. Убедитесь, что workflow **NBDT release gate** успешно прошёл build и Chromium smoke.
3. После успешного деплоя проверьте Overview на десктопе, ширине ноутбука и мобильной ширине; значения KPI должны совпадать с Configuration Report.

Полный архив `NBDT_Full_Project_v0_6_62.zip` содержит весь проект и доступен отдельно.
