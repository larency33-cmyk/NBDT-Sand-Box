# NBDT v0.6.62 — отражающее стекло и два ряда Overview

Основа: **v0.6.61**. Все изменения локализованы в Overview и версионном CSS-файле `nbdt-overview-v062.css`. Данные проекта, другие страницы, роли и права доступа не пересоздавались.

## Изменения Overview

- На четыре верхние KPI-карточки добавлены видимые **поверхностные отражения**: изогнутое отражение верхнего светового источника, диагональный зеркальный блик, прозрачная накладка над содержимым, стеклянная кромка, внутренние блики и мягкие цветные рефлексы.
- Полосы отражения реализованы CSS без внешних PNG, сохраняют читаемость показателей, не блокируют кнопки и поддерживают `prefers-reduced-motion`.
- Пять нижних панелей теперь расположены **строго в два ряда на широких экранах**:
  - Ряд 1: `Systems requiring attention` (8/12 ширины) + `This week` (4/12).
  - Ряд 2: `System readiness` (6/12) + `Recorded activity` (3/12) + `Ownership coverage` (3/12).
- Уплотнены таблицы, информационные карточки, промежутки, легенда владельцев, таймлайн событий и таблица готовности, при сохранении навигационных действий.
- Статусы этой недели и прогресс системы по-прежнему вычисляются из данных проекта. Последние события показываются компактно — 3 записи.
- На узких экранах включается удобная адаптивная компоновка; требование двух рядов относится к широким desktop-экранам.

## Контроль качества

- `node scripts/check-symbols.cjs`: **пройден** (7 TSX-файлов).
- `node --test tests/*.test.mjs`: **336/336 тестов пройдены**; добавлены отдельные тесты v0.6.62 на рефлексы и структуру сетки.
- Контроль синтаксиса TypeScript/TSX: **пройден**.
