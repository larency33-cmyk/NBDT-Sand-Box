# NBDT Hub v0.6.121 — Assignment: одинаковые интервалы и даты

- Белый промежуток между всеми верхними цветными карточками теперь точно соответствует отступу слева между Project и первой голубой карточкой: **4 CSS px**.

Сборка приложения требует установки npm-зависимостей; для production требуется отдельная проверка Vite и браузерный smoke test.
