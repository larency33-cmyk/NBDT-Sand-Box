# NBDT v0.6.40 — Approved Configuration Guide styling

Основа: NBDT v0.6.39. Изменена только страница открытого Configuration Guide.

## Реализация макета
- Все заголовки и названия в блоках выровнены по левой стороне.
- Верхний заголовок без отдельной иконки типа устройства.
- Technical essentials: без декоративной иконки и без Values to confirm.
- Поля сгруппированы в Device, Network, Access & management с карточками и аккуратными иконками этих трёх смысловых групп.
- Applications вынесены в самостоятельную фиолетовую панель (состав приложений считывается из appList в Guide).
- Lessons Learned выделен оранжевым и сохраняет открытие заметок.
- Configuration checklist: заголовок без декоративной иконки, трёхэтапный процесс сохранён, шаги оформлены плотными светло-голубыми строками.
- Экран чтения и редактирования технических данных использует прежний единый источник данных Guide, сохранены Save guide changes, публикация, этапы, чекбоксы и история.
- Добавлены адаптивные правила.

## Другие разделы
Weekly Tracker, Issue Tracker, System Registry, Configuration Report и боковое меню не изменялись.
