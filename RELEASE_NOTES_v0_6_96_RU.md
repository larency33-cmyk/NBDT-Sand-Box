# NBDT Hub v0.6.96 — Unified Registry Filters + Delete system

## Внешний вид фильтров

В System Registry три прежних нативных выпадающих списка **All platforms**, **All connections**, **All owners** теперь используют тот же дизайн и те же основные CSS-классы, что и **Device Type**:

- Выбор через белое выпадающее меню с иконками, подсветкой активной строки и галочкой выбранного значения.
- Закрытие при выборе, щелчке за пределами и клавишей Escape.
- Прокрутка длинного списка владельцев Assignment; имена берутся только из актуального Assignment.
- Сохранены прежние фильтры OS, network и Assignment owner, значения и логика Clear filters.

## Удаление карточки системы

Администратор открывает в System Registry карандаш на карточке → видит **Delete system** рядом с Save/Cancel. Нажатие показывает заметное подтверждение **Delete “System name” permanently?**. Только второе нажатие **Yes, delete system** запускает удаление.

Удаляется **выбранная запись системы** целиком: её описание, устройства, снимки конфигурации, истории развертывания, guide/checklist/review и другие вложенные в эту запись поля. Также удаляются записи **Issues**, непосредственно ссылающиеся на ID удалённой системы. Никакие соседние системы не затрагиваются.

**Важно:** записи Assignment и задачи Weekly Tracker управляются отдельно, поэтому не удаляются автоматически — система не может надёжно утверждать, что эти записи принадлежат исключительно данной карточке. Состав Assignment остаётся единственным источником информации о людях.

Другие существующие способы удаления системы (в Configuration Guide и Configuration Report) теперь используют общую операцию удаления, чтобы не оставлять связанные Issues.

### Проверить

1. Открыть System Registry, последовательно проверить Device Type, All platforms, All connections и All owners: единый внешний вид меню.
2. Убедиться, что фильтрация Windows/Wi-Fi/конкретного Owner даёт прежние результаты и Clear filters работает.
3. Под Admin открыть карандаш у **тестовой** системы, проверить, что Delete system требует отдельного подтверждения; отмена ничего не удаляет.
4. Подтвердить удаление только тестовой карточки: она исчезает из Registry и Configuration Report вместе с вложенной конфигурацией; другие системы сохраняются.
5. Убедиться, что запись Issue с точной привязкой systemId исчезла, а отдельные задачи Weekly Tracker и Assignment остались.
6. Перезагрузить страницу: удалённая система не восстанавливается.

Предупреждение: удаление необратимо без резервной копии. Рекомендуется проверять на тестовой системе.
