# NBDT v0.7 — Weekly Tracker UX Refinement

Дата: 21 октября 2026 г. Продолжение существующей версии v0.6, не новый сайт.

## Что изменилось

1. **Пустое четырёхнедельное окно**: вместо многократного `No tasks planned` — один компактный пустой экран. Можно вернуться к ближайшей неделе с реальными назначениями, сбросить фильтры, показать всех сотрудников или создать задачу в Edit mode. Никаких фиктивных заданий не добавляется.
2. **Динамические строки**: пустые строки ~62px вместо одинаковых высоких; заполненные ячейки растут под контент. В превью максимум четыре задачи с `+N more`.
3. **Интерактивные ячейки**: hover, focus, синяя выбранная рамка; клик открывает общую панель назначений сотрудника и конкретной недели. В пустой ячейке при Edit mode появляется отдельная кнопка `+ Add assignment` (не вложенная в другую кнопку): раскрывает выбор существующего задания в панели.
4. **Статусы**: Active — синий, Planned — серый, Done — зелёный, Blocked — янтарный. Имена задач не обрезаются в данных; tooltip сохраняет полное название. Helper обозначен отдельно.
5. **Сводка периода**: количество уникальных Task за видимые 4 недели (без двойного учёта задач, пересекающих недели) и отдельно за выбранную ISO-неделю, плюс статусы. Для Week — количество только за выбранную неделю, для List — за окно.
6. **ISO-навигация**: 11 видимых кнопок вместо 15, подсветка текущего четырёхнедельного диапазона, отдельный сильный акцент на якорной неделе, стрелки для перехода на четыре недели, корректное отображение года на его границе.
7. **Верхняя панель**: более короткий период (`13 Jul – 9 Aug 2026`), Master Timeline стал вторичным действием.
8. **Поиск**: debounce 250ms, поиск также по описанию и категории задач. Совместимость фильтров и ролей Owner/Helper сохранена.
9. **На мобильных**: остаются карточки по сотрудникам и опциональная локально прокручиваемая матрица; hover-only действие также доступно на touch-экранах.

## Что не менялось

- Реальные записи, примеры и демо-содержимое не переписаны.
- IndexedDB и правила сохранения, TaskEditor, Issues, System Registry, Guide, Configuration Report, Master Timeline и Cable Hub не заменены.
- Системы и количество устройств не подменены числами из эталонных PNG.
- Новые улучшения ограничены Tracker и общим исправлением helper-кнопки B, которая теперь сохраняет переданный CSS-класс без потери базового `nb-button`.

## Подтверждённые проверки

- `npm test`: **80/80 PASS** (72 прежних + 8 новых контрактных тестов для Weekly Tracker).
- `npm run check:syntax`: синтаксических ошибок в index.tsx, src/workspace.tsx, src/enhancements.tsx, vite.config.ts **0**.
- `redesign.css`: успешно разобран PostCSS (синтаксис корректен).
- Проверено наличие файла, тестов, настроек Vercel и исходных эталонов.

**Ограничения:** в данной среде нет установленных React, Vite, Tailwind и других npm-зависимостей. Попытка `npm install` была прервана по тайм-ауту. Полная сборка, dependency-aware lint, реальные Playwright browser checks и визуальная регрессия нового интерфейса не подтверждены. Поэтому архив — доработанные исходники, а не протестированный production build. Перед публикацией в Vercel обязательно установить зависимости, выполнить `npm run lint`, `npm run build` и проверить все три режима Weekly Tracker на соответствующих ширинах.

## Установка и сохранение данных

1. Перед заменой сайта на том же/другом домене используйте Overview → Demo data, backup & audit → Export project backup (JSON). Если домен остаётся прежним, IndexedDB обычно сохраняет данные, но всё равно сделайте backup.
2. Распакуйте проект, запустите `START_WINDOWS.cmd` на Windows (Node.js 22.12+ и доступный npm registry), либо `npm install && npm run dev`.
3. Проверьте пустой диапазон, `Show all people`, `View scheduled assignments`, открытие панели после клика на ячейку, кнопку `+ Add assignment` в edit mode и переход к Week.
4. Сборка: `npm run lint`, затем `npm run build`. После успешной сборки можно отправлять в Vercel; размещённый сайт не изменялся этим архивом.
