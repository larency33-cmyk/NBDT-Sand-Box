# NBDT: первая версия редизайна

Это измененный исходный проект, а не изображение интерфейса.

## Запуск
Распакуйте архив в отдельную папку. Откройте терминал в этой папке:

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает Vite. Не заменяйте рабочий сайт этой версией без проверки.

## Что изменено
- Светлая рабочая область и темная боковая навигация.
- System Registry: компактные карточки, технические параметры, Open guide.
- System Guide: Technical essentials, Lessons Learned, три этапа checklist.
- Weekly Tracker: Overview / Week / List, фильтры, панель назначений.
- Configuration Report: новые KPI-карточки и общая светлая тема.
- Master Timeline и исходные редакторы сохранены.

## Безопасный локальный режим
По умолчанию Firebase отключен. Данные записываются только в отдельное хранилище браузера. Локальная версия не загружает актуальные данные из Firebase. Начальные записи взяты из исходного кода, это не актуальный статус проекта.

Для редактирования нажмите Edit mode / Admin Mode. В локальном режиме поле допускает любое значение: это переключатель для проверки интерфейса, а НЕ защита. Не публикуйте эту версию как защищенное приложение.

## Границы этой версии
Это первая реализация по референсам, не точная копия всех пяти изображений. Per-device checklists, Preparation, роли помощников и отдельная метрика Deployed не добавлены: в исходной модели нет соответствующих данных. Существующие checklist относятся к системе в целом.

Backend, SQL Server, Docker и корпоративная авторизация не внедрялись. Текущая версия предназначена для локальной проверки интерфейса.

## Проверки
TSX синтаксис проверен. Полную сборку и браузерные проверки выполнить не удалось: установка npm-зависимостей в среде подготовки не завершилась. Поэтому версия требует локального тестирования; отсутствие ошибок сборки не гарантируется.
