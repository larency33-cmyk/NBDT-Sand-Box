# NBDT v0.6.3 — начать здесь

Это новая версия **от принятой v0.6.2**, не от отклонённой v0.7.

1. **Экспортируйте резервную копию** в текущем развёртывании через `Overview → Demo data, backup & audit → Export project backup`. Новая версия не очищает IndexedDB, но менять сайт без backup рискованно.
2. Распакуйте архив и запустите `START_WINDOWS.cmd` (Node.js 22.12+ и доступ к npm) либо `npm install && npm run dev`.
3. Weekly Tracker теперь содержит только **Overview** и **List**. Внизу находится навигация **Week 1, Week 2, Week 3…**, стрелки и Today.
4. **Week 1 начинается точно в Project start**, даже если это суббота. Например: 28 Mar – 3 Apr 2026, Week 2: 4–10 Apr. Номер года или ISO-Wxx нигде в нижней ленте больше не показывается.
5. Откройте **Edit mode**, нажмите ячейку сотрудника/недели. В правой панели: выберите статус задания — он сохраняется в общий Task; `+ Add assignment` добавляет одно поле названия и сохраняет Planned-задание этому человеку на эту неделю. Если статус Blocked без причины, интерфейс попросит её в этой же панели.
6. Изменение `Project start` сдвигает **даты** недель и сохраняет привязку задач к их порядковым номерам. Указанные вручную `dueDate` не сдвигаются. Дата меняется только после подтверждения.
7. `Add task` в заголовке по-прежнему открывает расширенный редактор. Milestones и другие разделы не удалены.
8. Прежде чем выкладывать на Vercel, выполните `npm test`, `npm run lint`, `npm run build` и визуальную проверку в браузере. Здесь полная сборка не подтверждена.

Подробности и ограничения: `NBDT_v0_6_3_release_notes_RU.md`.
