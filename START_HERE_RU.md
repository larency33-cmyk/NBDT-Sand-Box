# NBDT v0.5 — начать здесь

**Это новый архив исходников с редизайном пяти рабочих экранов по эталонам пользователя.** Весь предыдущий проект v0.4 сохранён и продолжен; числа и записи не заменены примерами из изображений.

1. **Сохраните резервную копию** текущих данных: Overview → Demo data, backup & audit → Export project backup. Смена Vercel-домена или браузера не перенесёт IndexedDB автоматически.
2. Откройте `NBDT_v0_5_visual_redesign_report_RU.md`: изменения по всем пяти экранам, ограничения и проверка.
3. Скриншоты эталона находятся в `design_references/`, а подробные правила — в `NBDT_Website_Master_Specification_RU.md`.
4. Для локального запуска используйте `START_WINDOWS.cmd` (Node.js 22.12+, интернет для npm) или команды в `README.md`.
5. Перед публикацией требуются `npm run lint`, `npm run build`, браузерная и визуальная проверка. В среде сборки архива npm registry был недоступен.

**Проверено:** 64 автоматических unit/static-теста, TSX-синтаксис, статические bindings, CSS-синтаксис. **Не проверено:** production Vite build, реальное отображение в Chromium новой версии. URL уже развёрнутого сайта не затрагивался.
