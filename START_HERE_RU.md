# NBDT v0.6.6 — с чего начать

Это обновление **существующего NBDT v0.6.5**, выполненное по утверждённому светлому макету Weekly Tracker. Не применять v0.7: её изменения ранее были отклонены.

1. В текущем развёртывании сохранить backup: **Overview → Demo data, backup & audit → Export project backup**.
2. Распаковать архив, установить Node.js 22.12+, запустить `START_WINDOWS.cmd` (или `npm install`, затем `npm run dev`).
3. Проверить Weekly Tracker Overview: текущая неделя с голубой подложкой, остальные недели с мягким чередованием, milestones спокойных оттенков, кнопки нижних недель с датами/днями и выделением сегодняшнего дня.
4. Нажать на ячейку сотрудника — правая панель должна открываться **поверх**, без сжатия четырёх колонок. Проверить быстрый статус и добавление задания.
5. Выполнить `npm test`, `npm run lint`, `npm run build`. Полноценную сборку локально здесь подтвердить не удалось из-за отсутствующих npm-пакетов.
6. Перед публикацией сравнить экран с `design_references/approved_weekly_tracker_light_accents.png` на рабочем мониторе и проверить мобильный вид.

Изменения и границы проверки: `NBDT_v0_6_6_release_notes_RU.md`.
