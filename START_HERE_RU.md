# Начать здесь

1. Прочитать IMPLEMENTATION_STATUS_RU.md: версия не завершает всю спецификацию и не готова к production.
2. Сохранить backup данных старого сайта. Старый localStorage автоматически не переносится.
3. Распаковать архив в отдельную папку, не поверх единственной рабочей копии.
4. Команды запуска и проверок приведены в README.md.
5. Проверить npm run lint и npm run build до публикации. В среде подготовки архива полная установка зависимостей не завершилась.

Что реально проверено: 47 unit tests и 17 изолированных Chromium checks. Логи в verification/.

Edit mode не является авторизацией. SQL Server/API/SSO не реализованы. Живой сайт не изменялся.
