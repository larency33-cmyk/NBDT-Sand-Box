# NBDT v0.6.2 — начать здесь

1. Сохраните backup проекта из предыдущего развёртывания через **Overview → Demo data, backup & audit → Export project backup**.
2. Новая версия построена на принятой **v0.6.1**, не v0.7. Исходные данные и другие страницы сохранены.
3. Запустите на Windows `START_WINDOWS.cmd` с Node.js 22.12+ или вручную `npm install`, `npm run dev`.
4. В **Weekly Tracker** в режиме редактирования настройте **Project start**. Единственный календарь относится к старту проекта; к другим неделям переходите через стрелки внизу и Today.
5. Добавляйте milestone через `+` в заголовке нужной недельной колонки. Событие редактируется как отдельная сущность, без Owner.
6. Перед Vercel проведите `npm run build` и визуальную проверку. Это не было полностью выполнено в среде подготовки.
7. Макет для сверки: `design_references/Approved_Weekly_Tracker_v062.png`.

Читайте `README.md` и `NBDT_v0_6_2_release_notes_RU.md`.
