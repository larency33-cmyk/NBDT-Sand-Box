## Календарная модель

Проект хранит **реальную дату начала** `startDate`, заданную редактором. Календарные ISO-недели вычисляются с понедельника недели, в которую попадает эта дата. Для `2026-01-30`: W05 = 26 Jan–1 Feb, W06 = 2–8 Feb, W07 = 9–15 Feb. Это осознанное правило: иначе неделя с пятницы по четверг не может называться ISO-неделей.

Текущая неделя определяется по `project.timezone` (по умолчанию Europe/Paris). Выбранная в URL неделя имеет приоритет при загрузке прямой ссылки. При открытии без такого параметра — отображается текущая. При смене проекта или даты начала без явного week используется текущая календарная неделя, но для проекта в будущем — первая допустимая.

Если пользователь меняет дату старта, локальная запись сохраняется транзакционно существующим механизмом IndexedDB. Чек-листы, профили устройств и реальные значения не переписываются. Позиции задач относительно проектной сетки (`startWeek`) сохраняются. Явные Due Date не меняются автоматически. Milestone date корректируется на календарный сдвиг ISO-якоря, чтобы соответствовать проектному расписанию.

## Milestone

- Плюс в шапке добавляет событие конкретной ISO-недели (в Edit mode).
- Редактор содержит название, описание и milestone date; изменение даты автоматически меняет неделю события.
- Milestone не имеет Owner/Helpers, не засчитывается как обычная задача в счётчиках, хранится в той же модели Task с `isMilestone: true`.
- CSV/JSON, восстановление ранее сохранённых milestone и импорт не отклоняются из-за отсутствия Owner.
- Без события отображается `No milestone`; это не фиктивная запись.
