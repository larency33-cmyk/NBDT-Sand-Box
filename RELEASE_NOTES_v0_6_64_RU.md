# NBDT v0.6.64 — идеальные круговые индикаторы в Overview

**База:** v0.6.63. Изменена только визуальная часть четырёх верхних KPI-карточек Overview. Данные и функциональность всех других страниц сохранены.

## Что изменено

- Base Configuration, Ready for Deployment, Deployed и Cyber Approved используют **векторные SVG-кольца** со строго рассчитанной длиной дуги на основе процента выполнения. Это заменяет старую отрисовку из CSS conic-gradient, которая могла давать заметные рваные границы и наложения.
- Для заполненной части кольца используется плавный, согласованный с карточкой цветовой градиент, округлённые края и аккуратная бледная дорожка.
- Внутри каждого кольца добавлен **полупрозрачный жидкий слой**, который медленно колышется двумя независимыми волнами. Это только декоративная анимация: значения прогресса и правила их расчёта не изменены.
- Для `prefers-reduced-motion: reduce` движение волн полностью отключается.
- Иконки Settings2, Rocket, Layers3, ShieldCheck перенесены в ряд **слева от крупного процента**, увеличены до 37 px (с адаптивным уменьшением на узких экранах). Иконка, жидкость, обводка и фон карточки используют согласованную цветовую гамму.
- Существующие элементы glassmorphism, навигация на Configuration Report и показатели KPI сохранены.
