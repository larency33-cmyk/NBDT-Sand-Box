# NBDT v0.6.56 — перестановка колонок сотрудников в Assignment

**База:** v0.6.55, включая исправление белого экрана и обязательные release checks. Все предыдущие изменения сохранены.

## Новый сценарий

- Admin / Super Admin: в заголовке колонки сотрудника добавлен небольшой захват **Move column**. Можно перетащить колонку на заголовок другого сотрудника — их позиции **обмениваются**, вместе с визуально расположенными под ними системами.
- Во время переноса исходная колонка приглушена, целевая подсвечивается на всю высоту, а отдельная карточка показывает сотрудника, число назначений и целевую колонку.
- После отпускания короткая подсветка показывает обе колонки в новом порядке. Если отпустить вне другого заголовка, порядок не изменится.
- Guest видит данные, но не получает управляющий элемент перетаскивания колонок.
- Можно пользоваться как мышкой, так и существующими возможностями сенсоров dnd-kit; горизонтальная прокрутка и перенос отдельных систем остаются.

## Важная логика сохранения

Сохраняется только новый порядок массива `assignmentRoster.people`; **ID сотрудников, должности, даты и связи всех систем с владельцами не меняются**. Поэтому на других страницах NBDT не происходит случайной смены Owner. Порядок переживает перезагрузку в рамках текущего браузера и отражается в CSV.

## Проверки

- **320 / 320 локальных автоматических тестов прошли**, включая 5 новых проверок обмена колонками, невозможности смены ролей Guest, сохранения данных и исполнения обработчика DnD через реальную скомпилированную TSX-функцию.
- `scripts/check-symbols.cjs`: без неопределённых символов и обращений до объявления.
- Проверка синтаксиса: успешна.
- **Полный Vite build и браузерный smoke-test здесь не запускались**: npm registry недоступен (`EAI_AGAIN`), а node_modules отсутствуют. GitHub release gate должен выполнить их до признания production-развёртывания подтверждённым. Не считайте успешные модульные тесты заменой реального браузерного теста.
