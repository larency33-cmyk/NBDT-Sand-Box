# NBDT v0.6.73 — Overview: фон воды и реальные приоритеты Configuration Remaining

База: **v0.6.72**.

## Изменения
- Пустая область внутри четырёх KPI-кружков теперь белая с прозрачностью **70%**, без изменения цветных дуг, волн и анимации.
- Configuration Remaining показывает **актуальную стадию** для каждой системы: Base Configuration → Ready for Deployment → Deployed.
- Ключевое исправление: процент, полоса прогресса, название стадии и количество остающихся устройств берутся **из одной стадии**, а не смешиваются с Base Configuration.
- Приоритет: Base, затем Ready, затем Deployed. Когда стадия завершена или имеет не менее **95%** и следующая стадия сильно отстаёт, акцент переходит на следующий этап.
- Системы с завершёнными всеми тремя стадиями исключаются из Configuration Remaining; незавершённый Deployment учитывается, даже если Base и Ready завершены.
- У трёх стадий собственные аккуратные цвета полос: синий, фиолетовый, бирюзовый.
- Отчётные данные не изменяются; на странице отображаются существующие значения, ограниченные допустимым диапазоном для безопасного расчёта процентов.
- Анимация жидкости и остальные страницы сохранены.

## Проверка
Запуск `npm test`, `npm run check:syntax` и контрольной проверки архивов выполняется перед выдачей. Браузерный production-build зависит от наличия локальных Vite-зависимостей.
