# NBDT Hub v0.6.118 — имена сотрудников и чистые цветные заголовки

Основа: v0.6.117 (`763586111fd781cf1d69d1965171fecba3df01c7`).

- Увеличены **имена сотрудников на 35%**: `10px → 13.5px`. Начертание и цвета сохранены.
- Круглые бейджи с инициалами увеличены **на 20%**: `28×28px → 33.6×33.6px`; сами буквы пропорционально `13px → 15.6px`.
- Верхние карточки сотрудников сохраняют согласованное скругление `12px 12px 10px 10px`, но убраны серые/внутренние окантовки и тени. Цвет правой и нижней границы точно совпадает с фоном каждой палитры (голубой, фиолетовый, мятный, персиковый, розовый).
- Высота **только** заголовков колонок увеличена с минимальных 111px до 123px для аккуратного размещения имен, даты и Move column. Высоты строк с системами не изменены.
- Без изменений: ширина семи видимых колонок, пошаговая навигация по одному сотруднику, редактирование, drag-and-drop с линией вставки, приглушенный текст систем, цвет пустых ячеек, все остальные экраны и данные.
- В двух исторических тестах v116/v117 ограничена область проверок соответствующей исторической версии CSS, чтобы они не блокировали новую санкционированную правку бейджей v118. Добавлены отдельные тесты всех новых требований.

Проверено: `npm run check:syntax` прошел; 645 успешных тестов, **23 прежних падения** (все названия совпадают с v117), новых падений нет. Изолированная CSS-визуализация проверена в Chromium при 1734×862, 1280×800, 900×700. Это **не** полная сборка приложения: `npm run build` завершилась после успешного symbol-preflight с `vite: not found` из-за отсутствующих npm-зависимостей.
