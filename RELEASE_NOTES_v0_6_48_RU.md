# NBDT v0.6.48 — управление входом в боковом меню

**Основа:** v0.6.47. Только UI и расположение панели доступа; хранилище, пользователи, роли и бизнес-логика не изменены.

## Изменения

1. **Guest / Sign in** перенесён из верхнего правого угла страниц в самый низ бокового меню, непосредственно над кнопкой **Collapse**. Текущий пользователь и уровень доступа отображаются компактной карточкой с иконкой.
2. После авторизации в этой карточке показываются **Admin** или **Super Admin**, логин, кнопка **Sign out**, а для Super Admin — **Manage admins** (переход к существующей Administration). Глобальный режим Edit не возвращается.
3. При сворачивании меню в узкую панель вместо широкой карточки появляется иконка аккаунта. Гость открывает Sign in по нажатию; вошедший пользователь открывает компактное меню действий.
4. Удалена видимая панель **Local UI sandbox** из нижней области бокового меню. Рабочая модель локального POC при этом не меняется.
5. Убраны зарезервированные пустые отступы под старый индикатор авторизации в правой верхней части Weekly Tracker, System Registry, Issue Tracker, Configuration Report и Administration. Управление аккаунтом отображается в одном месте на всех экранах.
6. Сохранены открытие окна входа, выход, переход к управлению администраторами, доступность кнопок и прокрутки, а также состояние свёрнутого меню.
