# NBDT v0.6.65 — исправление чёрных индикаторов Overview

База: v0.6.64. Сохранены все изменения v0.6.63 и v0.6.64, включая разделение Issues и Configuration Remaining, записываемую историю изменений, двухрядный Dashboard и увеличенные иконки.

## Причина дефекта

В предыдущем SVG-рендеринге часть заливок, градиентов и штрихов задавалась через CSS-переменные в SVG-атрибутах. В некоторых браузерных или деплой-сценариях браузер отображал такие нераспознанные значения как чёрный цвет. Движение жидких слоёв также было привязано к CSS-анимациям, которые могли отсутствовать или не применяться.

## Что изменено

- Цвета всех четырех KPI теперь передаются напрямую в SVG-элементы в явных HEX-значениях и `stopColor` через React, а не через `var(--...)` в SVG-атрибутах.
- Цвета кольца и жидкости согласованы: Base — синий, Ready — фиолетовый, Deployed — бирюзовый, Cyber — зелёный.
- Линии прогресса имеют гладкие круглые концы и точную длину для каждого процента.
- Две волны в каждом кольце анимируются SVG `animateTransform` с разными периодами, не зависят от загрузки внешних CSS-анимаций.
- Символы KPI остаются слева от процентов, крупные и окрашенные в цвет своей карточки. Критические значения размеров и цвета заданы inline для устойчивости при частичной потере CSS.
- Общая структура Overview, все данные, маршруты, права доступа и остальные разделы не менялись.

## Контроль

- 351/351 unit tests passed.
- `npm run check:syntax` и `node scripts/check-symbols.cjs` прошли.
- Векторные SVG-кольца дополнительно проверены статическим рендером CairoSVG; никаких чёрных сегментов при рендеринге не было.
- **Не подтверждены** полная Vite-сборка и тест анимации в браузере на production: npm-зависимости в среде отсутствуют, Chromium не завершил прогон. Проверьте GitHub Actions release gate и Vercel после обновления.
