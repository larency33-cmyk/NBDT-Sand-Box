# NBDT v0.6.65 — Premium Overview: глянцевые KPI и компактная аналитика

База: **v0.6.64**. Дата: 1 ноября 2026.

## Изменения

- Четыре KPI в верхнем ряду (Base Configuration, Ready for Deployment, Deployed, Cyber Approved) получили более заметную, но сдержанную стеклянную поверхность: полупрозрачные слои, тонкий диагональный блик, светлую внутреннюю обводку и мягкую тень.
- Сегментированный полукруг **по-прежнему остаётся единственной графической шкалой прогресса** каждой KPI; показатели берутся из прежних источников и не дублируются дополнительной полосой.
- Медленные волны снизу KPI сохранены. При `prefers-reduced-motion: reduce` анимация отключается.
- Systems requiring attention и This week получили более плотные строки и отступы, а пустой список Milestones перестал требовать большую внутреннюю высоту.
- Нижняя аналитика на широких экранах теперь располагается в трёх колонках: **System readiness** | **Recorded activity** | **Ownership coverage**. На средних экранах — две колонки, на узких — одна; таблица System readiness имеет горизонтальную прокрутку, если не помещается.
- Числа, проценты, категории, ключи Assignment, связи с Issues и Weekly Tracker, вкладки, боковое меню, админские функции и backend-модель не менялись.
- **Demo data, backup & audit** уже удалён из Overview в предыдущем релизе; в v0.6.65 не возвращается.

## Проверки и известное ограничение

- Все существующие и новые автоматические тесты проходят (363/363).
- `npm run check:syntax` и `node scripts/check-symbols.cjs` проходят.
- CSS корректно разбирается PostCSS.
- Полная Vite-сборка и production browser smoke test **не подтверждены**: `vite` отсутствует, а установка npm-зависимостей в текущей среде не завершилась. GitHub release gate должен выполнить `npm install`, `npm run build`, `npm run smoke:production` перед деплоем. Нельзя считать это подтверждённой браузерной сборкой.
