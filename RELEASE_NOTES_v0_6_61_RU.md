# NBDT v0.6.61 — Operational Overview (30 октября 2026)

База: v0.6.60. Обновлена только страница Overview и небольшая поддержка навигации в Configuration Report; остальные рабочие модули и записи сохранены.

## Данные и связь разделов

| Блок Overview | Источник | Расчёт / поведение | Куда ведёт |
|---|---|---|---|
| Base Configuration | Configuration Report, `reportCounts(project,counts)` | Принятые этапы/значения агрегатов / общее число устройств | Configuration Report |
| Ready for Deployment | Тот же источник | Готовые к развёртыванию устройства / общее число устройств | Configuration Report |
| Deployed | Тот же источник | Развёрнутые устройства / общее число устройств | Configuration Report |
| Cyber Approved | Те же записи и фильтрация применимости, что в Report | Approved / applicable systems, а НЕ процент устройств | Configuration Report |
| Systems requiring attention | Issue Tracker, Blocked задачи Weekly Tracker и данные устройств в Configuration Report | Сначала открытые Critical/High issues, потом блокировки, затем остатки конфигурации и развёртывания; никаких вымышленных проблем | По Issue → Issue Tracker с выбранной проблемой; по неготовой системе → Configuration Report с поиском по её имени |
| This week | Weekly Tracker (`startDate`, `timezone`, tasks, milestones) | Проектная неделя от даты начала, Planned/Active/Blocked/Done только для задач, относящихся к текущей неделе; milestones текущей и следующей недели | Weekly Tracker |
| System readiness | Реестр систем + Configuration Report | Крупнейшие по Qty учтённые системы, три разных процента готовности, без смешения с Cyber | Configuration Report с фильтром по имени |
| Recorded activity | IndexedDB audit журнала POC | Только фактические записи сохранения данных проекта и каталога Assignment; нет искусственных имён/типов изменений | Информационный блок |
| Ownership coverage | Точное совпадение имени системы с Assignment | Unique owner / shared owners / no match среди систем в Registry; количество строк Assignment указано отдельно | Assignment |

## Реактивное обновление

- Компонент получает `displayProject` и `assignmentRoster` из общих React-состояний сайта.
- Пересчитывает метрики при создании/изменении/удалении системы, изменении устройств и progress, изменении Cyber, изменении статусов задач, issues, milestones и переносе владельцев через Assignment.
- Текущая проектная неделя также обновляется по времени каждые 60 секунд (часовой пояс проекта).
- Изменение имени системы в реестре влияет на точное соответствие Owner; неоднозначность не скрывается и не выбирается произвольно.
- Состояние поиска в Report устанавливается только при явном переходе к конкретной системе из Overview, не изменяет записи.

## Точность данных

- Никакого общего Overall Completion, выдуманных приростов +%, несуществующих milestones, выдуманных событий или дополнительных систем.
- KPI с нулевым знаменателем показывают `—` вместо вымышленного 0%/100%.
- Если проект использует `referenceDemoTotals`, исходный Report включает иллюстративную нерасписанную часть агрегатов. Это честно отмечено внизу Overview; данные нельзя выдавать за подтверждённый инвентарь.
- `Cyber Approved` использует другую единицу измерения/знаменатель, чем три этапа устройств.
- Задача Weekly Tracker не превращается автоматически в статус системы и наоборот.
- Данные POC сохраняются в локальном IndexedDB и не синхронизируются автоматически между компьютерами.

## UI

- Новый профессиональный дизайн Overview в корпоративной палитре NBDT.
- Четыре KPI, основная таблица приоритетов, текущая неделя, список готовности систем, подтверждённый журнал и покрытие Owner.
- Кликабельные карточки, переходы к оригинальному разделу, скролл/адаптивность, reduced motion, состояния отсутствия данных.
- Никаких новых кнопок Edit Mode; сама Overview остаётся read-only.
