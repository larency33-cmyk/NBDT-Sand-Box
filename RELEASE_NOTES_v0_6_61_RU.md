# NBDT v0.6.61 — Overview glass effect and dashboard reorganization

База: **v0.6.60**. Изменение визуальное и композиционное для страницы **Overview**; существующие данные, маршруты и рабочие разделы проекта не удалялись.

## Что изменено

- Верхние 4 KPI-карточки на странице **Overview** полностью переработаны в более премиальный стиль с выраженным эффектом стекла / глянца.
- Для карточек добавлены: прозрачный glassmorphism-фон, световой блик, более глубокая тень, кольцевые индикаторы и более явная визуальная иерархия значений.
- Нижняя часть Overview была **перекомпонована**, чтобы убрать ощущение разбросанности и сделать выравнивание более логичным.
- Новый состав и порядок блоков Overview:
  - **Systems requiring attention**
  - **This week**
  - **Recorded activity**
  - **Ownership coverage**
  - **System readiness**
- Блоки теперь собраны в плотную сетку с более аккуратными отступами, одинаковой геометрией карточек и согласованным выравниванием заголовков, таблиц и вспомогательной информации.
- Добавлены компактные progress bars для Base / Ready / Deployed прямо в Overview.
- В шапке Overview добавлены компактные информационные карточки с датой старта проекта и текущей проектной неделей.

## Что не менялось

- Данные Weekly Tracker, Configuration Report, Issue Tracker и Assignment не удалялись.
- Навигация между разделами сохранена.
- Изменение касается в первую очередь представления данных на странице Overview.

## Контроль перед релизом

- После правок рекомендуется выполнить стандартные проверки: `npm install`, `npm test`, `npm run build`, `npm run smoke:production`.
- Если эти команды не были выполнены в текущей среде, релиз следует считать **неполностью верифицированным**, даже если исходники упакованы корректно.
