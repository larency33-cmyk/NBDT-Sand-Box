# NBDT v0.6.68 — оптическая глубина стеклянных KPI

Основа: v0.6.67. Изменения локализованы в четырёх круговых индикаторах Overview (Base Configuration, Ready for Deployment, Deployed, Cyber Approved).

## Изменения

- Под основной дугой процента добавлена более тонкая и светлая внутренняя дуга. Обе рассчитаны от одного процента, поэтому всегда показывают одинаковый прогресс.
- Под поверхностью жидкости добавлена вторая, полупрозрачная волна с независимым мягким движением: ощущение глубины без тяжёлого 3D.
- В стеклянной сфере появились внутренняя кромка, рефракция, мягкий световой отблеск и лёгкая тень в нижней части.
- Цветовые темы сохранены: синий, фиолетовый, бирюзовый и зелёный. Все эффекты максимально локализованы внутри кругов, карточки остаются в общем плоском стиле NBDT.
- Существующая жидкостная анимация v0.6.67 не удалена. Режим `prefers-reduced-motion: reduce` отключает движение.
- Данные проекта, роли, связи владельцев, маршруты и прочие страницы не изменялись.

## Проверки

- 358 / 358 автоматических тестов прошли.
- `scripts/check-symbols.cjs` и `scripts/check-syntax.cjs` прошли.
- Изолированное отображение карточек проверено в Chromium; движение дополнительной волны подтверждено сравнением CSS-преобразований через 700 мс.
- Полная production-сборка Vite и smoke-test всех маршрутов в этом окружении не подтверждены из-за отсутствующих локальных зависимостей. Проверка должна завершиться в GitHub Actions после загрузки обновления.

## Обновление GitHub

При обновлении с v0.6.67 использовать отдельный архив `NBDT-068-GITHUB.zip`: он содержит только новые и изменённые файлы с сохранением путей.
