# NBDT Hub v0.6.126 — одинаковая ширина KPI и System readiness

В Configuration Report четыре карточки Base Configuration, Ready for Deployment, Deployed и Cyber Approved теперь занимают всю доступную ширину, совпадающую с внешними левым и правым краями блока System readiness.

## Детали
- Исправлен только горизонтальный размер общего контейнера четырёх KPI. Сохраняются одинаковые ширины карточек и промежутки между ними.
- Отступы по 24 CSS px, заметные на скриншоте, компенсированы по обеим сторонам. На узких экранах компенсация сбрасывается, чтобы не создавать горизонтальный выход за область.
- Анимированные жидкостные круги, исходные данные, таблица, фильтры и интерактивные функции не изменены.
