# NBDT v0.6.66 — Живая жидкость в KPI Overview

База: v0.6.65. Изменены только индикаторы четырёх карточек **Base Configuration**, **Ready for Deployment**, **Deployed**, **Cyber Approved**. Остальные блоки и данные не изменены.

## Исправления

- Вместо практически незаметной повторяющейся SVG-анимации (SMIL) использованы отдельные HTML/CSS-слои жидкости внутри окружности. Это исправляет впечатление статичного заполнения.
- **Две волны** плавно перемещаются по горизонтали и слегка наклоняются с разными скоростями; поверхность «дышит» на 1–2 px.
- Добавлены **редкие маленькие пузырьки** с низкой прозрачностью, которые медленно всплывают и исчезают, а также едва заметный перелив внутреннего блика.
- Цветовые оттенки жидкости приглушены до пастельных, соответствуют цвету каждой карточки и не отвлекают от процентов.
- Векторная дуга прогресса остаётся стабильной, цветной и привязанной к фактическому проценту; проценты не изменяются из-за анимации.
- При системной настройке `prefers-reduced-motion: reduce` анимации останавливаются, сохраняя статичный, читаемый вид.
- При 0% заливка полностью скрывается.

## Проверка и защита от повторного регресса

- Добавлены исходные регрессионные тесты CSS-анимации и фиксированной SVG-дуги.
- Production browser smoke test усилен: теперь Overview должен показать четыре кольца и вычисленный transform волны должен измениться между двумя моментами (если режим reduced motion не включён).
- Локально проверена работа CSS-анимации в Chromium на отдельно собранном HTML-предпросмотре с реальными каскадными стилями проекта. Проверялись кадры и computed transforms через 1.25 / 3.35 секунды.
- Полная Vite-сборка и runtime smoke test всего приложения в текущей среде не подтверждены из-за отсутствия npm-зависимости `vite`; запуск требуется выполнить в GitHub Actions/Vercel.

## Состав обновления

Затронуты `src/workspace.tsx`, `index.tsx`, новый `nbdt-overview-v066.css`, `scripts/smoke-production.cjs`, регрессионные тесты и метаданные релиза. Все остальные функциональные разделы сохранены.
