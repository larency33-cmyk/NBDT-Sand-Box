# NBDT Hub v0.6.107 — исправление описания и удаления системы

Основа: проект v0.6.106; затронут только System Registry.

1. При нажатии карандаша поле **Description** теперь содержит существующий текст карточки; если у старой системы описание никогда не сохранялось, в редактор подставляется ровно тот текст-заполнитель, который был показан на карточке. Так пользователь сможет исправить или заменить его, а не начинать с пустого поля.
2. Кнопка «Delete system» удалена из редактора описания. В режиме редактирования **слева от карандаша** появляется отдельная **красная иконка корзины**.
3. Нажатие корзины открывает отдельное подтверждение с названием системы и явным предупреждением: будут безвозвратно уничтожены сведения системы, конфигурация/руководство, устройства, чек-листы, история развёртывания и связанные Issues. Действие возможно только после явного подтверждения «Yes, delete system»; «Keep system», Esc и клик по затемнённой области отменяют операцию.
4. Операция удаления по-прежнему доступна только администратору; используется существующий `deleteRegistrySystem` без изменений. Независимые задачи Weekly Tracker и Assignment не удаляются.
5. На небольшом экране кнопки и диалог остаются доступными.

Изменения не касаются welcome/SSO, графики и анимаций, баз данных, задач, остальных разделов.
