# NBDT v0.6.100 — детализация стартовой сцены

Доработка по сравнению фактической страницы с согласованным пиксельным макетом.

- У четырёх сотрудников восстановлены подробные силуэты, одежда, руки и позы. Вместо упрощённых геометрических фигур используются отдельные прозрачные спрайты по исходному рисунку. Движения головы и рук сохранены отдельными слоями.
- Тележка получила детальный корпус, ручку и колёса. На коробке теперь миниатюрный знак N/судно, соответствующий макету. Этот же рисунок коробки используется при упаковке.
- На заднем плане добавлены несколько планов пиксельных гор, береговая линия и светлые облака с мягким движением. На телефоне фон обрезается отдельно от переднего плана и не закрывает подписи соседних этапов.
- Имена меняются каждые **8 секунд вместо 20**, то есть в 2,5 раза быстрее. Подстановка следующей группы происходит, пока плашки скрыты.
- Доставка сохраняет прежний 20-секундный темп. Периоды доставки, смены имён и облаков сходятся на общей бесшовной границе 40 секунд; используется одна временная шкала.
- Дополнительный общий спрайт-атлас занимает 139 201 байт. Оба атласа вместе — 693 929 байт. Новых библиотек и покадровых обновлений React нет.

Логотип команды, компоновка входа, временный переход по кнопке SSO, сохранение прямых ссылок и прежняя административная авторизация остаются как в v0.6.99. Для повторного просмотра открыть `/signin`.

Результаты проверок: `VALIDATION_v0_6_100.md`.
