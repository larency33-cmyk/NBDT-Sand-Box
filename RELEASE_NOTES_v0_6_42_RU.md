# NBDT v0.6.42 — Weekly Tracker: оформление выбора недели и управление Milestones

**Исходная версия:** v0.6.41. Другие разделы приложения, модели конфигурационных гайдов, данные устройств, Sidebar и Issue Tracker не менялись.

## 1. Текущая и выбранная недели — два разных состояния

- Голубая заливка в нижней навигации недель принадлежит **только реальной текущей неделе**, определяемой датой и проектным календарём.
- Если пользователь кликает по другой неделе, она получает **тонкую голубую рамку без голубой заливки**.
- Повторный клик, переключение диапазона четырёх недель и кнопка Today продолжают работать через прежнюю независимую `selectedWeek` / текущую дату; выбранная неделя не переопределяет реальную текущую.
- Геометрия колонок и выравнивание верхней таблицы с нижними неделями сохранены.

## 2. Milestones: создание, редактирование, удаление

- В режиме редактирования клик по существующему Milestone (или его карандашу в раскрытом списке) открывает компактный диалог. Можно изменить название и сохранить.
- В диалоге существующего Milestone появилась **Delete** с отдельным подтверждением. Удаляется только Milestone с указанным ID; обычные задачи не удаляются.
- Добавление Milestone также открывает компактный диалог с тем же именованным полем, вместо `window.prompt`.
- Сохранение/удаление использует прежний общий `handleAction`, поэтому проектное состояние сохраняется прежним механизмом IndexedDB. При ошибке диалог остаётся открытым с пояснением.
- В обычном режиме просмотра редактирование и удаление недоступны.

## 3. Много Milestones в одной неделе

- В обычном состоянии шапка недели остаётся прежней фиксированной высоты и показывает первый Milestone, а для дополнительных появляется `+N more`.
- При наведении курсора на шапку с несколькими Milestones, либо при переходе фокусом / раскрытии счётчика, список разворачивается **поверх карточек ниже**. Это отдельный абсолютный слой, не увеличивающий строки матрицы и не сдвигающий задачи.
- Развёрнутая часть стилистически продолжает цвет и обрамление шапки текущей недели. Длинный список получает внутреннюю прокрутку.
- Если Milestone один или список пуст, полноценный раскрывшийся список не показывается; кнопка добавления доступна при наведении в Edit mode.

## 4. Реализация

- `src/workspace.tsx` — редактор, модальное окно и список Milestones.
- `src/tracker-actions.mjs` — `quickDeleteMilestone` c проверкой типа записи.
- `index.tsx` — связывание обработчика удаления с исходным механизмом сохранения и подключение CSS.
- `weekly-tracker-milestones-v042.css` — точечные стилевые изменения последним импортом, чтобы прежняя корпоративная тема не переопределяла новые правила.
- `tests/milestone-interactions-v042.test.mjs` — проверка основных новых сценариев.
- `package.json` — номер версии 0.6.42.
