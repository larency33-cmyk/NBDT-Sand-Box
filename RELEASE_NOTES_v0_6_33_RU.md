# NBDT v0.6.33 — Continuous & Inline Configuration Report

Основа: v0.6.32. Изменён только экран **Configuration Report**, боковая навигация и Weekly Tracker остались неизменными.

## Изменения

1. **Нет пагинации**: все системы (в том числе системные профили, добавленные пользователем) показываются в одной непрерывной таблице, прокрутка страницы стандартная. Фильтры, сортировка и скрытие столбцов сохраняются.
2. **Редактирование внутри таблицы**: нажмите значок карандаша в строке системы. На месте ячеек появляются поля Name, Device model, Qty, Venue, Base, Ready, Deployed, AW, Cyber и Owner. Save / Cancel доступны в столбце Actions. Отдельное модальное окно удалено.
3. **Создание внутри таблицы**: Add system вставляет редактируемую строку прямо под заголовками. После сохранения новая система записывается в данные проекта и IndexedDB.
4. **Удаление с подтверждением внутри строки**: Delete доступен при активном режиме редактирования; подтверждение и отмена встроены в ту же строку, без модальных окон. Удаление использует существующий обработчик сохранения и удаляет связанные Issues, как ранее.
5. **Проценты только из Qty**: в каждой из колонок Base configuration, Ready for deployment, Deployed показано одно число готовых устройств, процент и полоска прогресса. Вычисление `round(100 × completed / Qty)`; значения от 0 до Qty, целые, неотрицательные. Во время ввода процент пересчитывается мгновенно, после Save обновляется верхний KPI.
6. **Аудит Cyber**: при изменении статуса Cyber появляется компактное поле «Reason / evidence» в той же ячейке.
7. **Проверенные device runs** не подменяются ручными числами. Если система содержит зарегистрированные устройства и нет режима демонстрационных агрегатов, числовые поля недоступны: прогресс таких систем ведётся через чек-листы.
8. Обновлено CSS-оформление редактируемых строк, действия компактно расположены справа; устаревшие CSS правила модального редактора удалены.

## Данные и оговорки

6 систем из утверждённого макета и 2 существовавшие системы сохранены. Примерные KPI 88% / 26% / 12% / 48% включают **отдельный иллюстративный остаток для 68 невидимых систем**, созданный в предыдущей версии. Данные этого остатка не являются реальными показателями склада. Изменения конкретной системы правильно сдвигают расчётные суммы. Это не серверная синхронизация: проект по-прежнему использует локальную IndexedDB.
