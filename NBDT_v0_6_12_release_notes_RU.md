# NBDT v0.6.12 — утверждённый Weekly Tracker

База: **NBDT v0.6.11**. Реализация по загруженному пользователем окончательному макету от 24 октября 2026 г.

## Изменения

1. Верх каждой из четырёх недельных колонок содержит название `Week N`, фактический диапазон дат, круглый chevron выбора недели, а ниже milestone. Ранее там были только milestones. Нажатие круглой кнопки **выбирает неделю, не прокручивая окно**.
2. Размеры таблицы и нижних карточек синхронизированы одним набором CSS-переменных. Employee = 255 px на широком экране, 212 px при ≤1250 px. За счёт фиксированной ширины первой колонки Chromium распределяет остальные четыре столбца строго одинаково. Устранили ошибку CSS `clamp(...,% ,...)`, из-за которой Chromium фактически делил таблицу на **пять равных колонок**, а footer — иначе.
3. Нижние карточки Week 1–4 начинаются **точно под своими колонками**. Уравнены отступы внутренней части таблицы и нижнего grid; устранены горизонтальные смещения 49 px / 31 px, обнаруженные на тестовых десктопных разрешениях.
4. Переработаны визуальные акценты: только текущая неделя обладает заливкой; соседние недели слегка чередуются; небольшие статусные бейджи с читаемым контрастом; milestone-плашки в едином стиле; строки и иконки сотрудников выровнены.
5. **Сохранено без изменения**: проектная нумерация, независимые `currentWeek`, `selectedWeek`, `visibleStartWeek`, кнопки Previous/Next/Today, отдельная всплывающая панель быстрого редактирования задач, сохранение IndexedDB, остальные разделы NBDT.

## Контроль геометрии

Изолированная проверка CSS в Chromium (1774 / 1440 / 1150 px) показала совпадение координат `x` начала каждой недели в `<thead>` и соответствующей нижней карточки: расхождение **0.00 px** на проверенных ширинах. Проверка относится только к разметке/геометрии экрана в изолированном контейнере, **не равнозначна запуску полного NBDT**.

Автотесты `npm test` и проверка `node scripts/check-syntax.cjs` выполнены (результаты: `verification/v0612-test-summary.txt`). Полную Vite-сборку выполнить в среде подготовки не удалось: установка npm-пакетов не завершилась. Перед деплоем требуется `npm install`, `npm run lint`, `npm run build` и браузерная проверка на вашем Windows Chrome.

## Обновление GitHub

К релизу предоставляются два ZIP: полный проект и только новые/изменённые файлы, которые можно распаковать **в корень репозитория**, сохраняя все относительные пути. Если есть сохранённые данные в IndexedDB, перед деплоем сделать резервный экспорт на сайте; ZIP не заменяет локальную базу браузера.
