# NBDT v0.6.26 — Calm Corporate Weekly Tracker

Основа: чистая v0.6.25. Изменения касаются **только визуального оформления Weekly Tracker**; левое меню, данные и другие экраны не менялись.

## Дизайн

- Week Blue — спокойный голубой, Week Violet — приглушённая лаванда, Week Orchid (внутреннее название палитры) — мягкий абрикосовый, Week Mint — деликатный мятный.
- Цвет привязан к **номеру проектной недели**, а не к позиции колонки на экране.
- Текущая неделя: уверенный синий контур и мягкая голубая заливка сверху, в заданиях и нижней навигации.
- Другие недели: почти белые карточки задач с деликатными границами и тенями.
- Значения и цвета статусов Active / Planned / Done / Blocked не менялись.
- Палитра верхней части правой панели соответствует выбранной проектной неделе.
- Даты и дни недели сохранены в нижней навигации; логика milestones и задачи не затронута.

## Изменённые файлы (по сравнению с v0.6.25)

- `index.tsx` — подключён новый стилевой слой последним.
- `package.json` — версия `0.6.26`.
- `weekly-tracker-corporate-v026.css` — новый стилевой слой, ограниченный трекером.
- `tests/corporate-week-palette-v026.test.mjs` — новые регрессионные проверки.

## Проверки

- `npm test` — проверены тесты, включая новые.
- `npm run check:syntax` — проверены синтаксические файлы TSX.
- CSS разобран парсером PostCSS, ошибок нет.
- Отдельный тест в Chromium по встроенному статическому DOM: цвета применяются, нижние карточки недель сохраняют геометрию относительно колонок. Проверены ширины 900, 1150, 1440, 1536, 1774 px.

**Ограничение:** полная Vite production-сборка и функциональность в запущенном приложении не проверены (npm-зависимости не установлены в этой среде). Тест Chromium использовал облегчённый DOM-макет; не подтверждает пиксельную точность полноценного React-приложения.
