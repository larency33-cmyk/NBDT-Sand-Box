# NBDT v0.6.16 — утверждённый Weekly Tracker

## Основа
- Полный исходный проект v0.6.15. Остальные экраны, модель задач и IndexedDB сохранены.
- Точный визуальный ориентир: `design_references/approved_weekly_tracker_2026-10-24_final.png` (скриншот пользователя).

## Реализация макета
1. Узкая боковая навигация **только на экране Weekly Tracker**; другие разделы без изменений.
2. Светлая палитра, плотные фильтры и KPI, небольшое расстояние перед началом календарной матрицы.
3. Отдельная скруглённая шапка у каждой недели (12px), мягкие светло-голубые/белые колонки с тонкими разделителями и без общей внешней рамки.
4. Реальная текущая неделя единственная с голубой подложкой; выбранная неделя выделяется рамкой внизу.
5. Проектные недели с датами + 7 днями недели; текущий день получает синий маркер.
6. Стрелка Previous **внутри первой** нижней карточки, Next **внутри четвёртой**. Клик сдвигает видимый диапазон на одну проектную неделю.
7. Today — под Project weeks с иконкой календаря, насыщенным синим цветом; возвращает к текущей проектной неделе.
8. Правая панель быстрых задач остаётся слоем над матрицей, не меняет ширину колонок.

## Точность геометрии
`src/workspace.tsx` измеряет **фактические ширины пяти ячеек TH** через `getBoundingClientRect()` и применяет те же ширины (в том числе дробные пиксели) к пяти track нижней навигации. `ResizeObserver` пересчитывает после ресайза. На узких экранах скролл нижней ленты синхронизирован с единственным горизонтальным скроллом матрицы. Никаких самостоятельных нативных полос прокрутки у нижних карточек нет.

Изолированная проверка Chromium (`verification/check_approved_v016.py` и `verification/v016_geometry_check.json`) при ширинах 1774 / 1536 / 1440 / 1150 / 900 px: **0 px** расхождения верхних колонок и нижних карточек; обе стрелки внутри карточек.

## Ограничение проверки
Тесты логики и TSX-syntax проходят, изолированный Chromium рендер проверен. Полный `npm run build` и сравнение всего реально запущенного React-приложения с макетом **не подтверждены**, так как установку npm-зависимостей завершить не удалось.
