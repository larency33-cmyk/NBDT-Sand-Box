# NBDT Hub v0.6.87 — Clear filters в верхней панели System Registry

## Что изменено

- Кнопка **Export** удалена только из заголовка **System Registry**. Экспорт в других разделах не изменён.
- На прежнем месте кнопки Export появляется аккуратная кнопка **Clear filters** с иконкой **FilterX**.
- Она видна только при активном условии фильтрации: текст поиска (кроме пробелов), **Device Type**, **Platform**, **Connection**, **Owner**.
- Кнопка очищает все эти значения одновременно, после чего исчезает.
- Кнопка под строкой фильтров удалена, поэтому при фильтрации не появляется лишняя строка.
- Кнопка доступна и гостям: очистка фильтров не является административным изменением.

## Проверка

1. Открыть System Registry без фильтров: Export нет, Clear filters тоже нет.
2. Ввести название системы в поиск: справа сверху появляется Clear filters.
3. Нажать Clear filters: поиск очищается, список восстанавливается, кнопка исчезает.
4. Повторить с Device Type, Platform, Connection и All owners, отдельно и в комбинации.
5. Войти под Guest: сброс фильтров должен работать.
6. Проверить заголовок на узком экране: кнопка должна оставаться рядом с действиями, не добавляя отдельную строку под фильтрами.
