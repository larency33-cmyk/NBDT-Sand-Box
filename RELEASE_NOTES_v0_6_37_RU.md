# NBDT v0.6.37 — System Registry template alignment

Основа: v0.6.36. Изменён только экран **System Registry** и связанные с ним категории устройств.

## Изменения

1. Карточки System Registry полностью переработаны под утверждённый шаблон: крупный заголовок, иконка слева, кнопка редактирования справа, блок характеристик, отдельный блок Description и две нижние кнопки.
2. Добавлены новые типы визуализации устройств: **Phone, Tablet, PC, Laptop, Kiosk, POS, App only**.
3. Для карточек и легенды добавлены новые иконки типов устройств, включая отдельную иконку **App only**.
4. Слово **Description** сделано жирным, описание вынесено в отдельный цветной блок. Для длинных описаний добавлен переключатель **Show more / Show less**.
5. Поля карточки приведены к шаблону: **Device model, OS, Connection, Naming**.
6. В верхней части страницы добавлена легенда с типами устройств и строка **Showing X of Y systems**.
7. В редакторе системы расширен список категорий устройств: теперь доступны **POS** и **App only**.

## Не изменялось

- Weekly Tracker
- Issue Tracker
- Configuration Report
- Configuration Guide

## Примечание

Категории **POS** и **App only** поддерживаются в проекте. Если конкретная карточка не переведена на новый тип вручную в данных проекта, для неё используется наиболее подходящий визуальный тип по существующей категории или названию системы.
