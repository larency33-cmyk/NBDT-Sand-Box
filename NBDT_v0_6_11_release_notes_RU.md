# NBDT Web Project v0.6.11 — Native Scrollbar Arrows Fix

## Исправление повторяющейся ошибки

В версиях до v0.6.10 включительно при переходе к следующей проектной неделе справа от нижней навигации в Chrome/Windows могли появляться четыре серые нативные стрелки прокрутки (горизонтальные и вертикальные), похожие на дополнительные кнопки.

Установлена конкретная причина конфликта CSS: прежний блок v0.6.10 в `redesign.css` повторно устанавливал `scrollbar-width:auto!important` для `.nb-tracker-table-wrap`. Этот стандартный параметр имеет приоритет над частью правил `::-webkit-scrollbar-*` и мог вернуть полосу прокрутки вместе с нативными кнопками. Дополнительно внешний `main` оставался горизонтально прокручиваемым.

В v0.6.11:

1. Удалён ошибочный блок `@supports ... scrollbar-width:auto`.
2. Нативные полосы прокрутки скрыты для **Weekly Tracker**, включая его матрицу, внешнюю прокрутку главной области, документ и milestones; другие разделы проекта не затронуты.
3. Вертикальная и горизонтальная прокрутка матрицы **не отключены**: остаются доступны колесо мыши, тачпад, клавиатура и касания на совместимых устройствах.
4. Нижние карточки недель остаются непрокручиваемым визуальным отражением таблицы; кнопка Next — отдельный контроль с высоким слоем.
5. Предотвращён автоматический scroll-to-focus при нажатии мышью на Prev / Next / Today (обычная клавиатурная навигация сохранена).

## Изменённые файлы

- `redesign.css` — устранение CSS-конфликта, скрытие нативных стрелок, сохранение скролла матрицы.
- `src/workspace.tsx` — защита Prev / Next / Today от автоматического скролла фокуса при нажатии мышью.
- `tests/scrollbar-search-focus-v0610.test.mjs` — тест под новую реализацию.
- `tests/week-arrows-v0611.test.mjs` — новые регрессионные тесты.
- `verification/week-nav-browser-smoke.py` — проверка CSS и клика навигации в реальном Chromium на тестовом макете (не полной React-сборке).
- `package.json`, `README.md`, `START_HERE_RU.md` и этот отчёт — метаданные и документация новой версии.

## Что проверено

- Запуск JavaScript unit/static-тестов `npm test`.
- TypeScript/TSX синтаксис: `node scripts/check-syntax.cjs`.
- Browser smoke в Chromium на тестовом DOM с **настоящим `redesign.css`**: 
  - клик Next: Week 1 → Week 2;
  - `scrollbar-width: none` для матрицы и документа;
  - `overflow: clip` для нижних карточек;
  - вертикальная прокрутка содержимого остаётся работоспособной;
  - размеры 1600px и 960px.

## Ограничения

Полный Vite/React browser-render и проверка на Windows с конкретной Chrome-темой пользователя не подтверждены в среде сборки — npm-зависимости здесь отсутствуют. Chromium smoke использует локальную тестовую разметку с реальными CSS-правилами, но не подменяет полный end-to-end тест.

## Установка

1. **Резервная копия**: до обновления экспортируйте данные IndexedDB текущего сайта.
2. `NBDT_Full_Project_v0_6_11.zip` — полный проект.
3. `NBDT_Changed_Files_v0_6_11.zip` — только добавленные и изменённые файлы с исходными относительными путями для GitHub (сравнение с v0.6.10).
4. Для проверки на машине с npm: `npm install`, `npm test`, `npm run lint`, `npm run build`.
5. После публикации на Vercel рекомендуется жёстко перезагрузить вкладку (`Ctrl+F5`) и несколько раз нажать Next/Previous.

Ни одна пользовательская задача, milestone, системный профиль или запись IndexedDB не изменена.
