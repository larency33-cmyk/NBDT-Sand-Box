# NBDT Project Workspace v0.6.3

Основано на пользовательской **v0.6.2**. Не переносит отклонённый v0.7.

## Главное изменение

Weekly Tracker использует **проектные**, а не календарные недели. Первая неделя начинается в дату `project.startDate`, каждая следующая — через 7 дней. Для проекта со стартом `2026-03-28` Week 1 = 28 Mar–3 Apr, Week 2 = 4–10 Apr. Продолжение нумерации не сбрасывается 1 января. Полное правило описано в `NBDT_Weekly_Tracker_v063_OVERRIDE_RU.md`, оно имеет приоритет над более ранней ISO-спецификацией.

Режимы Tracker: **Overview** и **List**. Панель выбранного человека/недели позволяет быстро менять статусы всех существующих заданий и добавлять задачу одной строкой. У одной задачи один глобальный статус для Owner и Helpers. Статусы сохраняются через `handleAction` в IndexedDB, не считаются сохранёнными до подтверждения операции. Открытые связанные blockers нельзя обойти быстрым статусом. Для ручного Blocked нужна причина.

## Windows: запуск

Установить Node.js >=22.12, распаковать архив, запустить `START_WINDOWS.cmd` либо в папке выполнить:

```bash
npm install
npm run dev
```

Создание production-сборки:

```bash
npm test
npm run check:syntax
npm run lint
npm run build
```

Vercel использует `vercel.json` с rewrite для глубоких URL. Обычная сборка создаёт `dist/` только при успешном запуске Vite.

## Данные и безопасность

До обновления сделать резервную копию через **Overview → Demo data, backup & audit → Export project backup**. Данные хранятся в IndexedDB браузера. Это не многопользовательская облачная синхронизация, а кнопка Edit mode не является серверной авторизацией. Никаких реальных систем или задач из макета в хранилище не подменяется.
