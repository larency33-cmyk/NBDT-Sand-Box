# NBDT Web Project v0.6.2 — Weekly Tracker Reference Match

Это продолжение **принятой v0.6.1** (которая основана на v0.6). Решения отвергнутой v0.7 не использовались.

## Что изменено

- Weekly Tracker Overview: отдельная строка необязательных milestones **над заголовком недели**, более плотная сетка задач, выровненные аватары, ясные статусы, синий фокус, компактная строка сводки и улучшенная навигация.
- Под таблицей ISO weeks есть работающие стрелки **Previous week / Next week**, выбор недели в ленте и переход **Today**. Верхний календарь недель удалён.
- Единственный календарь в Weekly Tracker — **Project start**. В Edit mode дата изменяется и после подтверждения сохраняется в локальном IndexedDB. Недели ISO начинаются с понедельника недели, содержащей дату начала проекта; так сохраняется правильная нумерация ISO. Пример: начало проекта 30 Jan 2026 означает первую ISO-неделю 26 Jan – 1 Feb 2026 (2026-W05), при этом дата проекта остаётся 30 Jan.
- По умолчанию при входе в проект открывается текущая неделя (по timezone проекта, по умолчанию Europe/Paris). Ссылка с явным `?week=2026-Wxx` сохраняет выбранную неделю. При нахождении пользователя на странице подсветка пересчитывается каждую минуту и после полуночи переходит к новой неделе.
- При смене даты начала проекта позиции задач по project week остаются такими же; даты недель смещаются. Явные dueDate конкретных задач остаются абсолютными. Даты milestones переносятся на сдвиг первой ISO-недели, чтобы они не выпали из закреплённой проектной недели. Перед изменением пользователь видит подтверждение.
- Milestones теперь редактируются отдельной формой без искусственного Owner; сохранение, изменение даты, удаление и JSON backup/import поддерживаются. Неопубликованные данные не подменяются макетными.
- Master Timeline удалён из активного пользовательского маршрута и основной JSX-реализации. Остались Overview, Week, List; другие разделы сохранены.

## Запуск

1. **Сделайте резервную копию данных текущего проекта**, открыв `Overview → Demo data, backup & audit → Export project backup`. IndexedDB привязана к браузеру и домену.
2. Установите Node.js **22.12+** и откройте проект на ПК с доступом к npm registry.
3. Запустите `START_WINDOWS.cmd`, или в терминале выполните:

```bash
npm install
npm run dev
```

4. Для публикации на Vercel убедитесь, что команды проходят без ошибок:

```bash
npm test
npm run check:syntax
npm run lint
npm run build
```

5. После публикации проверьте экран в Chromium при ширинах **1672, 1440, 1280, 768, 390 и 320 px**. Сверьте с `design_references/Approved_Weekly_Tracker_v062.png`.
