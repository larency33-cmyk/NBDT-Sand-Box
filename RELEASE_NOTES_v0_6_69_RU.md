# NBDT v0.6.69 — ровные индикаторы и заметная динамичная вода

Основа: **v0.6.68**.

## Изменения в Overview
- Полностью отключены объёмные слои стекла, блики и внутренние 3D-тени в четырёх круговых KPI.
- Цветная вода стала заметнее: применяется SVG-заливка с двумя контрастными волнами, которые двигаются независимо, без затуманивания.
- Высота заполнения зависит от фактического процента; 0% — пустой индикатор, 100% — заполненный.
- Основной круговой progress bar рисуется **одной** сплошной SVG-дугой с закруглёнными концами; устаревшая дополнительная дуга и оптические контуры скрыты.
- Все четыре фирменные цвета, иконки, карточки, проценты и навигация остаются прежними.
- Уважение `prefers-reduced-motion`: анимация выключается для пользователей с системным предпочтением уменьшенного движения.

## Проверки
- 361 автоматический тест успешно пройден.
- `scripts/check-symbols.cjs`: успешно.
- В Chromium протестирован изолированный рендер четырёх кругов, включая снимки в разные моменты; движение волн подтверждено.
- Полный production build Vite не запускался: зависимости в данной среде не установлены. Перед деплоем следует пройти стандартный GitHub release gate.

## Важное
Остальные страницы и данные проекта не изменены. ZIP для GitHub содержит только отличия от v0.6.68 с исходной структурой папок.
