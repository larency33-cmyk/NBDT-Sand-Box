# NBDT v0.6.59 — Configuration Report & Assignment polish

Основа: v0.6.58. Операции с системами, роли и данные сохранены.

## Изменения

1. **Assignment:** удалена кнопка `Export CSV` из верхней панели. Просмотр, поиск, редакторы и drag-and-drop сохранены.
2. **Configuration Report — Add system:** создание и редактирование больше не сбрасывают поиск, вкладку All / In progress / Not started, фильтры Venue / Owner / Cyber или текущую сортировку. После успешного сохранения система появляется в том месте списка, которое определяется текущей сортировкой.
3. **Визуальное подтверждение добавления:** новая строка мягко подсвечивается 3 раза (каждая вспышка 1 секунду). При появлении строки таблица плавно прокручивается к ней. Эффект не перезаписывает никакие данные и отключается при системной настройке уменьшения анимации. Если действующие фильтры скрывают новую систему, они остаются неизменными; система сохраняется, но не появится до изменения фильтра.
4. **Configuration Report:** полностью убран `Columns` из фильтров, все колонки отображаются. Сортировка по заголовкам таблицы остаётся доступной. Прежняя настройка скрытых столбцов более не применяется.
5. **Кнопки Export data / Import Report:** фон пространства между ними теперь прозрачный и совпадает с фоном страницы.

## Проверки

- Автоматические тесты и новые регрессии по сохранению состояния поиска/сортировки и трёхкратной подсветке.
- Компиляционная проверка TSX и проверка неизвестных символов/раннего обращения к переменным.
- Изолированный запуск компонента отчёта в режимах Guest и Admin.
- Полная Vite production-сборка и сквозная проверка Chromium **не выполнялись локально**: npm-зависимости недоступны. GitHub workflow `release-gate.yml` обязан выполнить build и браузерный smoke-test перед использованием в рабочем POC.

## Установка

- `NBDT_Full_Project_v0_6_59.zip` — все файлы приложения.
- `NBDT_GitHub_Changed_Files_v0_6_59.zip` — новые и изменённые файлы по сравнению с v0.6.58, с исходными относительными путями.

Для обновления GitHub заменить изменённые файлы из второго архива, дождаться успешных GitHub Actions и деплоя Vercel.
