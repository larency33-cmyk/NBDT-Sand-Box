# NBDT v0.6.34 — Approved Issue Tracker

Основа: GitHub main v0.6.33. Новая версия подготовлена в отдельной ветке `nbdt-v0.6.34-issue-tracker` без изменения рабочей `main`.

## Выполнено
- Новый светлый Issue Tracker по утверждённому макету. Иконка **не добавлялась** рядом с заголовком Issue Tracker.
- Вверху заголовок и подзаголовок, справа View/Edit mode и New issue.
- Общая панель поиска по названию/описанию и связанным системам, фильтры Severity и Assignee, кнопка Clear при активных фильтрах.
- Сводка активных, критических и высокоприоритетных проблем с датой последнего изменения.
- Четыре одинаковые колонки Open / Investigating / Waiting for parts / Resolved с количеством записей.
- В карточках подчёркнуты заголовок и описание. Система, приоритет, исполнитель, дата и ID вынесены в компактный вторичный блок.
- Для пустых колонок предусмотрено читаемое состояние. Сохранено перетаскивание между колонками (включая пустые) и вызов существующего редактора проблемы.
- Добавлены адаптивные правила для узких экранов.
- Остальные разделы приложения, включая Weekly Tracker, System Registry и Configuration Report, функционально не изменялись.
- Исправлено единственное устаревшее утверждение теста Weekly Tracker (дата в верхнем заголовке), не соответствовавшее ранее утверждённому дизайну.

## Данные и безопасность
Сохранение через существующие действия приложения; новых сервисов, учётных записей или постоянных внешних зависимостей не добавлено. Изменения находятся в отдельной GitHub-ветке до проверки.

## Архивы
- `NBDT_Full_Project_v0_6_34.zip` — полный проект.
- `NBDT_Changed_Files_v0_6_34_GitHub.zip` — изменённые и добавленные файлы с сохранением путей для загрузки на GitHub.
