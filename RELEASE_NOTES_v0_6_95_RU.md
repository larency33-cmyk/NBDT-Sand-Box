# NBDT Hub v0.6.95 — исправление ошибки сборки Vercel

## Причина сбоя v0.6.94

Vercel выдал `[vite:esbuild] Transform failed` в `src/workspace.tsx`: переменные `reassignError` и `setReassignError` были объявлены два раза внутри компонента Tracker. Новое окно **Reassign task** и существовавшее окно **Tasks to reassign** для исторических заданий случайно использовали один и тот же набор имён. Предварительный скрипт `check-symbols.cjs` не распознавал код TypeScript TS2451, поэтому префлайт проходил, а Vite останавливал сборку.

## Исправлено

- Старое окно исторических задач получило собственные `historicalReassignError` и `setHistoricalReassignError`; все связанные очистки, обработчики ошибок и текст сообщения переведены на это состояние.
- Новое окно Reassign task оставлено со своими `reassignError` и `setReassignError`.
- В предсборочную проверку `scripts/check-symbols.cjs` добавлены TypeScript-коды **TS2451** (дублирование переменных) и **TS2300** (дублирование идентификаторов), чтобы подобная ошибка обнаруживалась до Vite.
- Добавлен регрессионный тест `tests/tracker-build-guard-v095.test.mjs` на раздельные состояния обоих окон и наличие правильной проверки.
- Версия Node.js в `package.json` закреплена как `24.x`, чтобы совпадать с выбранной версией в настройках Vercel (ранее `>=22.12.0` автоматически выбирала Node 26).
- Добавлен GitHub Actions workflow `.github/workflows/verify-production-build.yml`: при коммите в `main` запускает установку зависимостей, настоящий `npm run build` и два регрессионных теста Reassign.
- Никакие задачи, статусы, участники Assignment и пользовательские данные не изменены.

## Как проверить

1. Проверить, что последняя версия успешно прошла этап `npm run build` на Vercel.
2. Открыть Weekly Tracker, выбрать сотрудника и неделю, затем любую задачу → `…`: новая кнопка **Reassign** должна отображаться.
3. Выбрать другого сотрудника из Assignment и другую неделю, сохранить.
4. Проверить, что задача переместилась и сохранила статус.
5. При наличии исторических задач проверить отдельное окно **Tasks to reassign** — ошибки не должны пересекаться с новым окном.

Причина предыдущего отсутствия Reassign: Vercel не смог собрать v0.6.94 и не развернул её. Очистка кэша браузера не могла устранить серверную ошибку компиляции.
