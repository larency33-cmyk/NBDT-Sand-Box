# NBDT v0.6.53 — критическое исправление запуска приложения

Основа: v0.6.52. Изменения минимальные, данные Assignment, проектные задачи и структура интерфейса сохранены.

## Причина белого экрана

Новая ссылка **Assignment** в боковом меню версии v0.6.52 использовала JSX-компонент `<Users />`, но `Users` отсутствовал в списке импортируемых иконок `lucide-react` в `index.tsx`. Из-за этого при первом рендере навигации возникала ошибка `ReferenceError: Users is not defined`. Главный компонент падал, оставляя вместо сайта пустой экран. Ранее выполнявшиеся проверки синтаксиса и тесты данных не ловили ошибку незадекларированной переменной.

## Исправления

1. Добавлен явный импорт `Users` из `lucide-react` в `index.tsx`.
2. Добавлен `scripts/check-symbols.cjs`: проверяет все TSX-файлы на отсутствующие символы (диагностики TypeScript TS2304/TS2552). Выполнение включено в `npm run build` **перед** командой `vite build`, чтобы будущие аналогичные ошибки останавливали деплой.
3. Добавлены два регрессионных теста: проверка импорта иконки Assignment и обязательной проверки символов перед сборкой.
4. Версия приложения обновлена до `0.6.53`.

## Проверки

- **302/302** автоматических теста успешно пройдены.
- Проверка TSX на неопределённые символы пройдена по семи TSX-файлам.
- При искусственном удалении импорта Users диагностируется TS2552; после восстановления импорта ошибка исчезает.
- Смоделированный запуск главного React-компонента выполнен для маршрутов tracker, systems, issues, reports/configuration, assignment и overview; модуль Assignment дополнительно проверен для Guest и Admin.
- Синтаксис TSX успешно транслируется TypeScript.
- Настоящая production-сборка Vite **не выполнена в этой среде**, потому что npm registry недоступен (EAI_AGAIN). После публикации в GitHub необходимо проверить успешность сборки Vercel и работу страницы в браузере.

## Для установки

Рекомендуемый способ: распаковать `NBDT_GitHub_Changed_Files_v0_6_53.zip` **в корень того же GitHub-репозитория**, заменив 8 файлов согласно относительным путям. Не удаляйте остальные файлы. После публикации обновите вкладку с сайтом через Ctrl+Shift+R.

## Сохранение данных

**Никаких изменений схемы данных и миграций нет.** Прежние данные IndexedDB, роли и Assignment из v0.6.52 остаются нетронутыми. Откат на v0.6.51 также не требует удаления IndexedDB.
