# NBDT Hub v0.6.108 — System Registry Progress Overview

Основа: v0.6.107. Утверждённый пользователем визуальный макет System Registry перенесён в интерфейс.

## Новый интерфейс
- В шапке каждой карточки отображается единый бейдж **Completed / In progress / Not started**; почти завершённые карточки (3 из 4) получают оранжевый оттенок, как в макете.
- После Owner добавлена полоска прогресса с реальным числом завершённых разделов **0/4–4/4**, затем четыре компактных индикатора **Base / Ready / Deploy / Lessons**.
- Цвета индикаторов: зелёный — завершён, синий — начат, серый — не начат. В подсказках доступны полные названия, состояние и число отмеченных пунктов / подтверждённых уроков.
- Добавлен шестой фильтр **All statuses**, с вариантами **Completed / In progress / Not started** в том же стиле раскрывающегося списка, что и остальные фильтры. Фильтр совместим с поиском, типом устройства, платформой, подключением и Owner. Clear filters очищает все фильтры.
- Три колонки карточек на широких экранах, две на средних, одна на узких. Сохранены иконки типов устройств, изменение описания, безопасное удаление, Owner, документация и переход Open guide.

## Важная логика готовности
- Для трёх стадий используются только сохранённые проверки **Guide (guideReview)**. Значение **Completed** возможно **только при принятом (Accept) и полностью корректном** чек-листе. Отмеченные, но ещё не принятые пункты дают In progress. Пустые или непройденные стадии дают Not started.
- **Lessons Learned** сверяет статусы review для **текущего проекта**: Completed — если все существующие Lessons confirmed; In progress — если есть хотя бы один review in-progress/confirmed, но не все confirmed; Not started — если уроки отсутствуют либо все pending. Отсутствие уроков автоматически не делает раздел завершённым.
- Устаревшие проверки с несовпадающим ключом Guide не засчитываются после изменения чек-листов.
- Прогресс устройств из `deviceRuns` не подменяет прогресс редактирования/проверки Guide.
- Общий статус: Completed — четыре раздела завершены; In progress — начата хотя бы одна стадия; Not started — ни один этап не начат. Полоса показывает **долю завершённых разделов**, не средний процент отдельных пунктов.
