# NBDT Hub v0.6.97 — индивидуальные значки подключений

В **System Registry → All connections** варианты подключения больше не используют одну и ту же иконку:

- **Wi-Fi** — значок Wi-Fi (беспроводная сеть).
- **Wired** — значок кабельного подключения.
- **All connections** — общий значок подключения, как раньше.

При выборе Wi-Fi или Wired соответствующий значок также появляется на кнопке самого фильтра. Цвет, размер, подсветка, галочка выбранного варианта и логика фильтрации не изменены. В остальных выпадающих списках по-прежнему используются общие значки их категорий.

Изменена только презентация фильтра; записи систем, Assignment, Weekly Tracker, Configuration Guide и прочие данные не затрагиваются.

## Как проверить

1. Откройте System Registry → All connections.
2. Убедитесь, что у Wi-Fi виден символ беспроводной сети, а у Wired — символ кабеля.
3. Выберите Wi-Fi: на кнопке фильтра должна появиться иконка Wi-Fi, а карточки должны фильтроваться по Wi-Fi.
4. Выберите Wired: кнопка показывает кабель, фильтр работает по Wired.
5. Сбросьте фильтры: появляется общий значок Network.
6. Проверьте другие три фильтра и карточки — без изменений.
