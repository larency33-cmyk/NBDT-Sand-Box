# NBDT Hub v0.6.104 — логотип ближе к заголовку

База: полная версия v0.6.103.

- Только **верхний логотип NBDT**, включая эмблему и подпись New Build Deployment Team, **сдвинут визуально вниз** на адаптивное расстояние (на обычных десктопах до 32 CSS px).
- Размер, пропорции, центрирование и ширина логотипа не изменены.
- Заголовок «Together, we bring ships to life.», подзаголовок и кнопка Sign in with corporate SSO остаются на прежних вертикальных позициях. Расчёт динамического центрирования учитывает смещение логотипа, поэтому остальные элементы не меняют положение.
- Для телефонов смещение 0–6 px; на низких экранах (≤520 px) смещение отключено для предотвращения наложений.
- Анимация, SSO-обработчик, брендовый PNG и изображение Configure → Deliver → Deploy не затронуты.
