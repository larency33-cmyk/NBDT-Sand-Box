# NBDT Hub v0.6.112 — приоритет названия при поиске в System Registry

На основе v0.6.111 изменён исключительно порядок результатов фильтра Search systems.

- Если введённые символы встречаются в **названии системы**, такая карточка отображается **раньше** карточек, найденных по Description / Device model / OS / Connection / Naming.
- Поиск по описанию и техническим полям **не удалён**: совпадения в этих полях по-прежнему отображаются, но ниже совпадений в названии.
- Совпадение ищется без учёта регистра, лишние пробелы вокруг поискового запроса игнорируются.
- Внутри каждой из двух групп сохраняется существующий порядок карточек; данные не мутируют и не записываются в другом порядке.
- Отдельные фильтры Device type, Platform, Connection, Owner и Status применяются до сортировки и работают как раньше.
- Без поискового запроса порядок систем не меняется.
- Карточки, чек-листы, SSO, импорт Excel и остальные разделы проекта не изменены.

Проверки см. в `VALIDATION_v0_6_112.md`.
