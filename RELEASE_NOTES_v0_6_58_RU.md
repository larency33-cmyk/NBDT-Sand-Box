# NBDT v0.6.58 — Configuration Report: упрощение Cyber

**Основа:** v0.6.57. Другие страницы, Assignment и их данные не изменены.

## Изменения

1. **Cyber → без Reason / evidence.** В строке таблицы больше не появляется дополнительный input при смене статуса; нет обязательного подтверждения или требования указывать причину. Достаточно выбрать значение и нажать существующую **Save**. Автоматическая история факта изменения Cyber (`status`, `actor`, `at`) продолжает записываться без текста причины.
2. **Unknown → Not Started.** Название изменено в выпадающем списке редактирования, фильтре, бейдже таблицы и экспорте. Добавлен единый нормализатор: старые `Unknown` и отсутствующие значения читаются как `Not Started`. Прочие значения `Review`, `Approved`, `Blocked`, `N/A` сохранены. В импорте поддерживается новое название; исторический `Unknown` принимается для совместимости.
3. **Удалено пояснение Reference demo** в нижней части Configuration Report. Данные, KPI, агрегаты и метрики не менялись.

## Проверки

- `npm test`: 324 теста успешны, включая четыре новых теста статусов и отсутствия Reason.
- `npm run check:syntax` и `node scripts/check-symbols.cjs`: успешно.
- Полную production-сборку Vite и smoke-test в Chromium локально не удалось выполнить из-за отсутствующих npm-зависимостей. После обновления GitHub обязательный workflow `release-gate.yml` должен проверить сборку и страницы до принятия релиза.

## Установка

- Полный архив содержит весь проект.
- Архив Changed Files содержит только новые и изменённые файлы относительно **v0.6.57**, с сохранением путей GitHub.
- Не удаляйте IndexedDB: это локальное хранилище данных POC.
