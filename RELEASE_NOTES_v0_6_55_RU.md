# NBDT v0.6.55 — исправление белого экрана и предотвращение повторений

**Основа:** v0.6.54. **Назначение:** устранение аварии запуска, без удаления и отката функций Assignment.

## Найденная причина

В `src/assignment-page-v052.tsx` зависимости `useEffect` ссылались на `people` и `rowCount` до объявления этих `const` переменных. Во время рендера React выполняется вычисление массива зависимостей, из-за чего возникал `ReferenceError: Cannot access 'people' before initialization` (в зависимости от момента — аналогично `rowCount`). Ошибка происходит до отображения страницы Assignment. Когда корневое приложение не может отрисоваться, пользователь видит пустой экран и на остальных маршрутах.

**Исправление:** объявление `people`, `itemsByPerson` и `rowCount` перенесено перед первым использованием этих значений. Логика данных, 13 исходных сотрудников, 108 назначений и изменения v0.6.54 сохранены.

## Новые обязательные проверки

- `scripts/check-symbols.cjs`: проверяет не только отсутствующие символы и импорты (`TS2304`, `TS2552`), но и обращение к ещё не инициализированным переменным (`TS2448`, `TS2454`), а также ошибки синтаксиса TSX. Встроен перед `vite build` — Vercel должен остановить публикацию при такой ошибке.
- `tests/runtime-release-gate-v055.test.mjs`: намеренно создаёт TSX с ошибкой и убеждается, что preflight её блокирует; проверяет наличие обработчика ошибок и сценария проверки всех маршрутов.
- `tests/assignment-render-v055.test.mjs`: компилирует реальный Assignment TSX и выполняет функцию отрисовки как Guest и Admin (изолированный runtime-тест без браузера).
- `scripts/smoke-production.cjs`: проверяет **реальную собранную Vite-версию** в Chromium: Overview, Weekly Tracker, System Registry, Issue Tracker, Configuration Report и Assignment, отслеживая необработанные JS ошибки, пустые заголовки и появление аварийного экрана.
- `.github/workflows/release-gate.yml`: выполняет unit-тесты, preflight, Vite build и smoke-test при push и pull request. Для запрета прямых небезопасных релизов необходимо включить required checks в GitHub branch protection.
- `NBDTRenderBoundary` в `index.tsx`: вместо полностью белого экрана показывает сообщение об ошибке и Reload, не очищая данные пользователя.

## Результаты локальной проверки

- **315 / 315 тестов успешно** (включая 2 теста отрисовки Assignment).
- Семантическая проверка TSX/инициализации и проверка синтаксиса выполнены без ошибок.
- **Полную сборку Vite и настоящий Chromium smoke-test в текущей среде выполнить не удалось**: npm registry недоступен, необходимых зависимостей нет. Поэтому развёртывание v0.6.55 следует считать **непроверенным в production** до успешного GitHub Actions release gate / Vercel build и визуальной проверки в браузере.
