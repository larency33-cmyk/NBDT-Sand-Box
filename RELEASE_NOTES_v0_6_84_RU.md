# NBDT Hub v0.6.84 — User account и очистка FALSE в Guide

## Исправлено

1. **Access & management** внутри System Guide: вместо `Owner` показывается **User account** из импортированного Excel (или из существующих системных данных). Поле видно также в режиме просмотра; его можно редактировать карандашом секции. Поле Owner в технической карточке больше не отображается.
2. **Owner** остался на **внешней карточке System Registry**; назначение владельцев через Assignment и связанные записи не изменены.
3. **Applications**: отдельные `false`/`FALSE` и флажковые значения после названий программ пропускаются при импорте. Они не выводятся даже для старых сохранённых записей; нормальный список программ остаётся. При редактировании/сохранении Applications сохранится очищенный список.
4. **Другие карточки Guide и Registry**: ошибочные одиночные значения `false` выводятся как `Not specified` (или тире в Registry), а не как текст `false`. При новом Excel-импорте такие одиночные значения полей не записываются.
5. **Импорт из Excel и пользовательские данные**: существующие Owner, Assignment, этапы Checklist и Lessons Learned не затрагиваются.

## Проверка вручную

1. Откройте System Registry и убедитесь, что Owner на внешней карточке остаётся.
2. Откройте тот же System Guide → Access & management: должна появиться строка User account с импортированным значением, без строки Owner.
3. Проверьте Applications в ранее импортированной карточке и после повторного импорта Excel: названия программ должны остаться, слова FALSE/false должны исчезнуть.
4. Войдите в редактирование Access & management и Applications: значения доступны и сохраняются.
