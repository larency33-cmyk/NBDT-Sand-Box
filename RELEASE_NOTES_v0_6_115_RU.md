# NBDT Hub v0.6.115 — переход ровно на одну колонку

Основа: v0.6.114. Раздел: Assignment.

- Одновременно видно до 7 колонок сотрудников, плюс фиксированная Project.
- Каждое нажатие навигационной стрелки влево/вправо сдвигает окно просмотра на **одну колонку**, а не на целую группу из 7: 1–7 → 2–8 → 3–9 → … → 8–13 (для 13 сотрудников; у администратора также доступна колонка Add person).
- Оставлена единственная пара стрелок и обновляющийся счётчик диапазона; крайние стрелки блокируются, когда идти дальше нельзя.
- Для быстрых последовательных нажатий добавлена защита от промежуточных событий плавной прокрутки: каждый клик учитывается как отдельный сдвиг. Ручная прокрутка мышью, касанием и клавиатурой сохранена.
- Все существующие системы/назначения остаются в DOM для перетаскивания между владельцами, редактирования и перестановки колонок.
- **Шрифты, размеры текста, высоты строк, цвета, логика хранения и другие разделы не изменены.**

Важно: это изменение UI и навигации, без миграции пользовательских данных.
