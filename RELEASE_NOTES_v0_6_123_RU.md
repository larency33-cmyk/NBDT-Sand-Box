# NBDT Hub v0.6.123 — Lessons Learned в Overview

- Карточка **Ownership coverage** заменена на **Lessons Learned** в фактическом Overview приложения.
- Статистика берётся из сохранённых уроков каждой системы в System Registry с учётом текущего проекта.
- Показываются все записи, подтверждённые (Confirmed), начатые (In progress), ожидающие проверки (Pending) и оставшиеся к проверке, а также системы без заполненных Lessons Learned.
- До трёх систем, требующих внимания, выводятся отдельными строками. По нажатию открывается соответствующая система в Open Guide.
- Старые заметки поддерживаются как одна запись, но не считаются подтверждёнными без статуса текущего проекта.
- Записи и статусы Lessons Learned, Configuration Guide и другие данные не изменяются.
