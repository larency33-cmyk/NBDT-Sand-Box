# NBDT v0.6.63 — сегментированные KPI с мягкими анимированными волнами

База: **v0.6.62**. Изменена только верхняя строка из четырёх карточек Overview. Все рабочие данные и разделы сохранены.

## Что изменено

- Четыре карточки **Base Configuration / Ready for Deployment / Deployed / Cyber Approved** получили единый полукруглый сегментированный индикатор, соответствующий последнему согласованному макету.
- Старые круговые донаты и дополнительные линейные progress bars в KPI **удалены**: только **одна** графическая шкала на одну карточку. Большой числовой процент и числитель/знаменатель оставлены для ясности.
- Шкала строится из **32 сегментов** с точным пропорциональным заполнением и частично заполненным пограничным сегментом. 0%, 7%, 10%, 22%, 49%, 78% и 100% проверяются отдельно. Если знаменателя нет, выводится «—» и пустая шкала, а не придуманный 0%.
- Цветовые темы: синий — Base Configuration, фиолетовый — Ready for Deployment, бирюзовый — Deployed, зелёный — Cyber Approved.
- Иконки уменьшены и упрощены. Поверхности — сдержанное матовое стекло, тонкие границы и лёгкая глубина.
- У нижнего края карточек две лёгкие волны с плавным переливанием **26 и 31 секунду** на цикл. Никакого мигания или движения цифр/индикаторов. При `prefers-reduced-motion: reduce` анимации отключены.
- При наведении карточка слегка приподнимается; видимый focus-outline оставлен для навигации клавиатурой. На узком экране карточки перестраиваются в две и одну колонку.

## Сохранённые связи

Все KPI продолжают считаться в существующей `buildOverviewData()` через общие функции Configuration Report. Первые три показателя измеряются в **устройствах**, Cyber Approved — среди **применимых систем**. Изменения Config Report автоматически меняют цифры и геометрию полукруга. Никакие демо-проценты из рисунков не добавлены. Нажатие на карточку по-прежнему переводит в Configuration Report.

**Не изменены** Sidebar, Weekly Tracker, System Registry, Issue Tracker, Configuration Report, Assignment, Administration, нижние блоки Overview, маршрутизация и POC-хранилище.

## Техническая реализация

- `src/overview-gauge.mjs`: чистая функция `gaugeGeometry(percent)` для геометрии SVG, значений 0–100, последнего сегмента и конечного маркера.
- `src/overview-v061.tsx`: SVG-компонент `SemiGauge` и две декоративные SVG-волны; удалено дублирование прогресса в KPI.
- `nbdt-overview-kpi-v063.css`: изолированный стилевой слой только для Overview, стеклянный эффект, стили индикатора, мягкая анимация и адаптивность.
- `index.tsx`: подключение нового CSS.
- `tests/overview-kpi-v063.test.mjs`: тесты точности сегментов, отсутствия дублирования, scope и reduced motion.
- `tests/overview-render-v061.test.mjs`: расширена проверка запуска и создания всех четырёх KPI-индикаторов.

## Установка

1. В GitHub загрузить **NBDT_GitHub_Changed_Files_v0_6_63.zip** поверх v0.6.62, сохранив относительные пути.
2. Дождаться успешного `NBDT release gate` (tests + production build + six-route Chromium smoke).
3. После успешного деплоя открыть Overview и проверить 4 карточки, реальное процентное заполнение и плавную волну.
4. Для резервирования исходников использовать отдельный **полный архив**.
