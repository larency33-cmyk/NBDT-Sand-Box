# NBDT v0.6.63 — Overview + Recorded Activity

База: **v0.6.62**. Предыдущий функционал страниц сохранён.

## Дизайн Overview

- Project start: более компактный текст, иконка флага слева.
- Current week: фирменный синий фон, иконка календаря, уменьшенные подписи.
- Base Configuration / Ready for Deployment / Deployed / Cyber Approved: иконки Settings2, Rocket, Layers3, ShieldCheck из Configuration Report. Тон градиента, иконка и прогресс-кольцо согласованы: синий, фиолетовый, бирюзовый, зелёно-бирюзовый.
- Внутри **Systems requiring attention** теперь два самостоятельных мини-блока: **Open issues** (реальные открытые Issues с критичностью) и **Configuration remaining** (объём незавершённой установки и настройки). Они не смешиваются.
- Сетка из двух рядов нижних карточек оставлена; карточки визуально уплотнены.
- Удалена служебная нижняя подпись Overview. Удалён видимый внизу Overview блок **Demo data, backup & audit**; существующие данные и механизм хранения не удалялись.

## Реальная история изменений

- В `src/activity-log.mjs` создан независимый модуль вычисления человекочитаемых различий до и после сохранения.
- Каждый успешный `handleAction` сохраняет записи в `project.activityLog` вместе с проектными изменениями (IndexedDB), до 200 последних событий.
- Поддерживаются: добавление, изменение и удаление систем; метрики Configuration Report и Cyber Status; изменения Device/Network/Guide, уроков, приложений, чек-листов; Issues; задачи и Milestones; участники проекта и дата старта.
- В отдельно сохраняемом Assignment отслеживаются добавления/правки сотрудников, передача систем между владельцами, изменения названий назначений и порядка колонок. После успешной записи каталога соответствующие изменения добавляются к истории текущего проекта.
- Recorded Activity показывает короткие сводки 3 последних действий. Кнопка **History** раскрывает сохранённый журнал до 200 записей.
- Старые изменения до версии 0.6.63 задним числом не восстанавливаются.
- Это локальная пользовательская история POC, **не серверный защищённый security audit** и не механизм синхронизации между компьютерами. Не сохраняет пароли и служебные поля.
