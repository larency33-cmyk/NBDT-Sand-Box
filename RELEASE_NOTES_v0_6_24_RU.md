# NBDT v0.6.24 — Inline Task Actions & Week-Matched Drawer

## Главное
- **Удалена отдельная страница `Edit task`**: компонент `TaskEditor` больше не экспортируется и не рендерится.
- Меню трёх точек на карточке задания в правой панели (видно в обоих режимах; изменение данных требует Edit mode) теперь содержит **Edit**, **Move to next week**, **Delete**.
- **Edit** открывает компактную форму прямо в карточке. Сохраняются название, описание, назначенный сотрудник, система, длительность и срок выполнения через существующую очередь изменений и IndexedDB.
- **Delete** требует отдельного подтверждения, предупреждает об удалении истории задания во всех неделях. Без подтверждения данные не затрагиваются.
- **Move to next week** выполняется за один клик в меню. Новая задача создаётся в следующей проектной неделе; из текущей она исчезает. Старые многонедельные записи корректно делятся, чтобы сохранить другие недели и не продублировать задачу в целевой неделе. Для новой недели создаётся новый ID и запись о переносе.
- Верхняя часть правой панели получает **тот же оттенок, что и соответствующий столбец недели** (blue/violet/orchid/mint). Дополнительная синяя верхняя полоса показывает текущую календарную неделю.
- Кнопка **Add task** на странице теперь открывает быстрое добавление внутри правой панели, без отдельного экрана.
- Создание и изменение milestones остаётся доступным через компактный запрос названия, без полноэкранного редактора.
- Боковое меню и остальные разделы не менялись.
