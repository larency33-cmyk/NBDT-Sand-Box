# NBDT Hub v0.6.127 — точное совпадение ширины KPI и System readiness

## Исправлено
- Четыре KPI-карточки Configuration Report теперь начинаются и заканчиваются **строго на тех же X-координатах**, что и внешняя рамка блока System readiness.
- Удалена ошибочная компенсация ширины ±24 px из v0.6.126. Внешний KPI-контейнер получает `width: 100%`, `padding: 0`, без отрицательных боковых отступов.
- Исправление не зависит от пиксельной ширины окна: оба блока — дочерние элементы одного контейнера `nb-report`.

## Без изменений
- Четыре анимированных жидкостных KPI, цвета, значения и подписи.
- Таблица System readiness, поиск, фильтры, редактирование и импорт/экспорт.
- Двухколоночная/одноколоночная адаптивная сетка на узких экранах.
