# NBDT v0.6.4 — Overlay Quick Assignment Panel

Основа: NBDT Web Project v0.6.3 — Project Weeks & Quick Edit. Остальные разделы проекта и схема данных не менялись.

## Исправление

Правое меню назначений Weekly Tracker теперь **всплывает поверх** неизменной четырёхнедельной матрицы, а не занимает долю её flex-контейнера. Таким образом при открытии меню не сжимаются столбцы, не меняется ширина таблицы и не ухудшается читаемость названий заданий.

- `src/workspace.tsx`: меню отрисовывается через `createPortal(..., document.body)` за пределами `.nb-tracker-content`. Вызовы выбора сотрудника и недели подключены к единому обработчику.
- `redesign.css`: новое фиксированное правое меню шириной до 490 px с мягким затемнением и тенью; внутри прокручивается только список заданий, верхняя шапка и Add Assignment остаются доступны.
- На экране до 760 px меню занимает весь viewport вместо сжатия основной таблицы.
- Кнопка X, клик за пределами меню и Escape закрывают его; фокус клавиатуры остаётся внутри модального окна и возвращается к выбранной ячейке после закрытия.
- Если есть несохранённый текст нового задания, перед закрытием запрашивается подтверждение. При сохранении нового задания меню не закрывается.
- Быстрое изменение Planned / Active / Done / Blocked, причина блокировки, добавление заданий, project-relative weeks, milestones, нижняя навигация и локальный IndexedDB сохраняются.

## Как запустить

1. Перед обновлением Vercel экспортируйте резервную копию данных из текущего приложения. IndexedDB привязан к origin браузера.
2. Распакуйте архив, установите Node.js 22.12+, выполните `npm install` и `npm run dev`.
3. Для публикации выполните `npm run lint`, `npm test` и `npm run build`.
4. В Weekly Tracker кликните любую ячейку сотрудник/неделя: справа появится панель, при этом четыре недели должны сохранить ширину и количество видимых заданий. Проверьте закрытие по X/Escape/клику за пределами, а также экран телефона.

Эта ревизия **не опубликована на Vercel** и не является утверждением о готовом corporate production deployment.
