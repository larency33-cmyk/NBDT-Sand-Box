# NBDT Hub v0.6.90 — Weekly Tracker: команда из Assignment, порядок строк и Not on site

## 1. Состав команды из Assignment

Weekly Tracker отображает **Team Lead** плюс **всех сотрудников из Assignment** (в исходных данных — 13 человек). Для каждого сотрудника показываются:

- **Name** — имя из Assignment;
- **Position** — ITO/ITSS (или другая должность из Assignment);
- **Joined** — дата присоединения из Assignment.

Названия, должности и даты автоматически обновляются при изменении состава сотрудников Assignment. Старые имена Weekly Tracker больше не добавляются как дубликаты. В самом Weekly Tracker отключены отдельные кнопки добавления, переименования и удаления сотрудников: состав команды редактируется в Assignment.

**Сохранность данных:** существующие задания, сроки, статусы и история не удаляются и не переименовываются автоматически. Если старое краткое имя однозначно соответствует сотруднику Assignment (например, HOMESH → HOMESHWAR HALKORI), прежний ID привязки сохраняется. Если соответствие неоднозначно или сотрудника нет в Assignment (например, JORGE или APPLE / NILSON), задание остаётся в строке **Unassigned**, с заметкой о предыдущем владельце в панели задания. После этого администратор может назначить владельца вручную. Количество реальных сотрудников в счётчике Weekly Tracker исключает служебную строку Unassigned.

Для безопасности другие разделы (например, Issue Tracker) продолжают использовать прежний список членов проекта; отдельно синхронизируется только команда Weekly Tracker. Не меняются записи Assignment, систем и Issue Tracker.

## 2. Порядок строк

Администратор может взять мышью **ячейку с именем** сотрудника слева и перетащить строку выше или ниже. Перемещается вся строка со всеми неделями, задания не перепривязываются к другому сотруднику. Во время переноса есть подсветка целевой строки. Для клавиатуры: фокус на ячейке имени, **Arrow Up / Arrow Down** для перемещения. Порядок сохраняется в проекте и после перезагрузки; изменения состава Assignment добавляют новых сотрудников, сохраняя вручную установленный порядок существующих.

## 3. Not on site для конкретной недели

Откройте карточку сотрудника в нужной неделе, затем в правой панели выберите **Mark Not on site**. После этого:

- Только эта ячейка недели становится серой, с надписью **Not on site**.
- Все ранее запланированные задания сохраняются со своими статусами и остаются доступны в панели.
- Другие недели и другие сотрудники не затрагиваются.
- Нажатие **Remove Not on site** возвращает обычный вид карточки.
- Управлять отметкой может только Admin/Super Admin; Guest видит статус без права изменения.

Данные хранятся в проекте через существующий механизм сохранения (не только в локальном состоянии компонента).

## Как проверить

1. Weekly Tracker содержит Team Lead и 13 человек из Assignment; имя, Position, Joined совпадают с Assignment.
2. Перетащить строку одного сотрудника выше другой, обновить страницу и проверить сохранённый порядок.
3. Поменять должность/дату в Assignment — значения обновляются в Tracker без дубликатов.
4. Открыть неделю выбранного сотрудника, нажать Mark Not on site, проверить серый стиль и неизменность задач.
5. Проверить другую неделю того же человека: она обычная. Убрать отметку и обновить страницу.
6. Проверить у Legacy-задач без соответствия наличие Unassigned и подписи Previous Tracker owner.
7. Проверить в Issue Tracker, что ссылки на старые имена не испорчены.
