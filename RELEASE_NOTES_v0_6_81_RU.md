# NBDT Hub v0.6.81 — исправление отображения Current Ship Review checkbox

## Причина ошибки

Общий стиль `redesign.css` задаёт всем `input` внутренние отступы `padding: 9px 12px`, а в основной области сайта также фиксирует белый фон через `!important`. Чекбокс в v0.6.79–v0.6.80 был нарисован **самим элементом `input`**, поэтому браузер мог визуально сжимать квадрат и мешать корректной заливке.

## Исправление

- Настоящий `<input type="checkbox">` сохранён, но теперь он визуально скрыт и используется только для доступного управления мышью/клавиатурой.
- Отдельный `span` рисует квадрат **26 × 26 px** без наследования общих стилей полей ввода.
- `Pending review` — светло-серый контур, `In progress` — синий контур, `Confirmed` — зелёный квадрат с белой SVG-галочкой.
- Сохраняется прежний порядок смены статуса: взаимодействие открывает редактор проверки, имя проверяющего обязательно для In progress и Confirmed.
- Остальной дизайн, исторические данные, существующие проверки, Excel-импорт и сохранение изменений не затронуты.
