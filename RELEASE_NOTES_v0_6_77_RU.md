# NBDT Hub v0.6.77 — исправление Excel paste для Lessons Learned

## Причина повторной ошибки

В предоставленном скриншоте текст формы ещё говорит «Copy four cells from one lesson row», а ошибка «Expected four Excel columns, but received 5» существует только в старом строгом обработчике. В версии v0.6.76 интерфейс использует адаптивный обработчик и другой текст формы. Поэтому скриншот, вероятно, показывает ещё не обновлённую сборку или старый кэш сайта.

Чтобы это можно было проверять самостоятельно, в панели импорта теперь есть небольшой маркер версии **v0.6.77**. После загрузки изменений в GitHub и успешного развёртывания Vercel откройте страницу заново (при необходимости Ctrl+Shift+R) и проверьте эту надпись.

## Изменения

- Улучшено распознавание старых Excel-файлов: физические 5+ ячеек могут содержать 3 содержательных колонки и пустые колонки-разделители. Пустые колонки очищаются без потери заполненных данных.
- Фрагменты DESCRIPTION, APPLICATION, AUTHOR и остальные подписи собираются в Issue Profile; COMMENTS, длинные пояснения и исправления — в Details / Corrective Action.
- Длинные примечания и подписи в конце текста (например, «Thank you! / Anastasiya Ryklina / Marine Business Analyst») сохраняются в содержании, а не принимаются за Resolved By.
- Если четвёртая ячейка является продолжением длинных Details, она добавляется к тексту, а не ошибочно записывается в Resolved By.
- Повреждённая/нестандартная HTML-часть буфера обмена больше не мешает использовать текстовую часть.
- **Fallback Preview:** когда формат однозначно разобрать не получилось, всё исходное содержимое сохраняется в поле Details / Corrective Action, заголовок остаётся пустым для ручного ввода. Никакие данные не теряются и повторно копировать из Excel не нужно.
- Сохранены все четыре редактируемых поля предпросмотра, существующие уроки по судам и обычное ручное редактирование.
- На интерфейсе «Paste from Excel» добавлен небольшой маркер **v0.6.77** для диагностики того, что новая версия действительно развернулась.

## Проверка

- `npm test` — 417 / 417 успешных тестов, включая 7 новых проверок Mobile ACP.
- `npm run check:syntax` — без ошибок.
- `node scripts/check-symbols.cjs` — пройдено.
- Полная production-сборка Vite и браузерный smoke-тест в текущей среде пока не подтверждены из-за отсутствия установленных npm-зависимостей.

## Как обновить сайт

1. Распакуйте `NBDT-077-GITHUB.zip` в **корень GitHub-репозитория**, сохранив пути файлов.
2. Дождитесь успешной сборки и Deploy в Vercel.
3. Откройте System Registry → System Guide → Lessons Learned → карандаш.
4. Проверьте, что в панели Paste from Excel виден маркер **v0.6.77**.
5. Скопируйте один урок в Excel (например, Mobile ACP); вставьте Ctrl+V; проверьте Preview, при необходимости отредактируйте; сохраните урок.

Новая версия не требует отдельного backend или платных AWS-сервисов. Хранение POC-данных остаётся локальным в браузере, как и ранее.
