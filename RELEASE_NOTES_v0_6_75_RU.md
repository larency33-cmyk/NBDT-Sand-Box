# NBDT Hub v0.6.75 — Excel Quick Import & Lessons Learned formatting

## 1. Lessons Learned

- У всех уроков в существующей оранжевой карточке добавлено автоматическое форматирование: `DESCRIPTION`, `APPLICATION`, `AREA / VENUE`, `PRODUCT TEAM`, `AUTHOR` и подобные заголовки превращаются в жирные подписи, даже если Excel скопировал их отдельной строкой без двоеточия.
- В `Details / Corrective Action` выделяются `COMMENTS`, `TRACKING`, `CORRECTIVE ACTION`, а также поля `Ticket` и `Ticket Date`.
- Всё происходит при отображении; текст уроков не переписывается и его Excel-импорт, группировка по кораблям и редактор v0.6.74 сохранены.
- Никаких новых статусов, фильтров или поиска не добавлялось.

## 2. Массовый импорт конфигурации в Guide

1. Авторизоваться как Admin / Super Admin, открыть `System Registry → нужная система → Open Guide`.
2. В верхнем правом углу выбрать **Import from Excel**.
3. В Excel выделить **всю область одного системного профиля**, включая значения и при необходимости три чек-листа. Скопировать Ctrl+C, затем вставить Ctrl+V в окно импорта.
4. В Preview проверить распознанные значения и количество шагов. Если некоторые строки не распознаны, их можно увидеть в отдельном списке *unrecognized lines* (они не применятся).
5. Нажать **Apply import**. Изменения сохраняются одним вызовом существующего `onUpdateSystem`. Существующие отдельные карандаши редактирования продолжают работать.

### Какие поля распознаются

- System name, Description.
- Endpoint (Device model), Platform, OS version, Device type, Naming convention.
- Network type, VLAN, IP scope, Reservation.
- Service account, User account, Auth type, Domain/OU, **AirWatch tags**.
- Applications List (несколько приложений).
- Check list — Base Configuration; Check list — Ready for Deployment; Check list — Deployment.

Сервис обрабатывает заголовки и значения отдельными ячейками (HTML/TSV из Excel), заголовки с двоеточиями и многострочный текстовый шаблон, похожий на предоставленный скриншот. Несуществующие или неподдерживаемые поля не изменяются.

### Безопасность данных

- Импорт **не трогает Lessons Learned**, другие существующие поля и профильные данные, если они не указаны в вставке.
- Списки шагов заменяются **только** для тех стадий, в которых найдены непустые шаги. Пустой заголовок чек-листа не удаляет уже записанные действия.
- Идентификаторы ранее совпадающих шагов сохраняются; новые шаги получают новые идентификаторы. Старые подтверждённые device runs и published guide сохраняются неизменными.
- Галочки из Excel считаются частью исходного текста/разметки и **не импортируются как факт выполнения**. Подтверждение выполнения происходит через существующую логику Guide.
- Замена OS блокируется для профиля с активными записями выполнений, как и при обычном ручном редактировании.
- Новая функциональность доступна только администраторам; содержимое копируется локально в браузере, не отправляется во внешние сервисы.
