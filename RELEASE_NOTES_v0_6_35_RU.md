# NBDT v0.6.35 — Issue Tracker: Search & Assignee Filter Polish

Основа: `NBDT v0.6.34` из актуальной ветки `main` репозитория `larency33-cmyk/NBDT-Sand-Box`.

## Изменения

1. **Верхняя панель Issue Tracker** — единая сетка из поиска, фильтра Severity и фильтра Assignee. Рамки всех полей ровные, непрерывные, одинаковой высоты; скорректированы скругления, границы, отступы и мягкая тень.
2. **Устранение причины исчезающих границ** — внутренний `input` больше не получает непрозрачную белую заливку из глобального стиля приложения. Вокруг поиска остается ровно одна рамка, а не две конфликтующие.
3. **Общий стиль фильтров** — вместо стандартного браузерного меню применены адаптивные выпадающие списки, согласованные с остальными контролами Issue Tracker: выбранный элемент выделен мягким голубым цветом и галочкой.
4. **Управление** — сохранены фильтрация и сброс; списки закрываются по клику вне них или Escape; поддержаны клавиши навигации вверх/вниз, Home и End, фокус возвращается к кнопке.
5. **Адаптивность** — на узких экранах поле поиска занимает свою строку, фильтры аккуратно располагаются ниже, на телефонах все поля в столбик.

## Не менялось

- Название и иконка около заголовка Issue Tracker (дополнительная иконка по-прежнему отсутствует).
- Данные, статусы, сохранение, карточки Issue Tracker, drag-and-drop.
- Weekly Tracker, Systems, Configuration Report, боковая навигация и остальные экраны.
