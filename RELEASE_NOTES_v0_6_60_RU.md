# NBDT v0.6.60 — Configuration Report toolbar background

База: **v0.6.59**. Изменение исключительно визуальное, данные и логика не затронуты.

- Исправлено белое поле между **Export data** и **Import Report** в заголовке Configuration Report.
- Причина: общий CSS `redesign.css` насильно превращал класс `bg-[#020617]` из старой тёмной темы в белый фон через более специфичный селектор с `!important`. CSS v0.6.59 пытался сделать фон прозрачным, но проигрывал по специфичности.
- Удалён конфликтующий dark-mode класс у контейнера кнопок, вместо него используется `bg-transparent`. Добавлен приоритетный scoped CSS, чтобы контейнер и дочерний блок оставались полностью прозрачными и показывали бледно-голубой градиент страницы.
- Размер, расположение, цвет самих кнопок, экспорт и импорт не изменены.

## Контроль перед релизом

- Регрессионный тест проверяет отсутствие тёмного класса у заголовка и наличие специфичного прозрачного слоя.
- Автоматические тесты / синтаксис: результаты приведены отдельно при выдаче.
- Vite production build и Chromium smoke test — требуются для подтверждения production; без npm-зависимостей не заявлять об их прохождении.
