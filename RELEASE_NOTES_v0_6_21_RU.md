# NBDT v0.6.21 — Premium Weekly Milestone Headers

- Перенесён цветовой стиль Week 3–6 из утвержденного изображения в **Weekly Tracker → Overview**.
- Цвет недели закреплён за её номером и не меняется при прокрутке: blue, violet, orchid, mint (цикл).
- Текущая неделя сохраняет отдельную синюю подсветку, выбранная — рамку в нижнем переключателе.
- Вверху виден только Week N и milestone: даты не дублируются вверху; диапазоны дат остаются только в нижней навигации.
- Milestone статусы Complete / Review / Critical сохраняют собственные смысловые цвета.
- Добавлены мягкие объёмные акценты заголовков, контуры и фон без fade-out, спокойные тени для карточек.
- Левое меню и остальные страницы **не изменялись**. Ширина нижних недель и логика стрелок не изменялись.
