# NBDT Web Project v0.6.6 — Approved Light Accent Layout

## Основа и объём работ

Проект взят из последнего принятого исходного ZIP **v0.6.5**. Это точная стилистическая доработка Weekly Tracker по утверждённому светлому изображению `design_references/approved_weekly_tracker_light_accents.png` без повторной разработки продукта и без демонстрационной подмены данных.

## Что изменено

1. **Иерархия акцентов**: сильный синий цвет остаётся у выбранной вкладки, главной кнопки, сегодняшнего дня и выбранной недели. Заливка текущей недельной колонки стала мягче; для неё сохранены тонкие боковые линии и верхний синий акцент.
2. **Соседние недели**: четыре колонки остаются читаемыми благодаря деликатному чередованию близких к белому холодных оттенков. Цвет распространяется на всю высоту ячеек.
3. **Milestones**: обычные события получают приглушённую сине-серую плашку; завершения/handover остаются зелёными. Критические/проверочные сохраняют отдельные семантические оттенки, но не спорят с выбранной неделей.
4. **Статусы задач**: Planned — серо-голубой, In Progress — синий, Completed/Done — зелёный, Blocked — тёплый оранжевый. Цветом выделяется надпись, не вся строка.
5. **Нижние карточки Project weeks**: избранная неделя выделена тонкой синей рамкой, остальные оформлены нейтрально; справа зарезервировано место для стрелки и Today, чтобы кнопки не перекрывали подписи дней.
6. **Панель быстрого редактирования**: сохранён overlay-режим из v0.6.4–v0.6.5; открытие панели не уменьшает ширину четырёх недель.
7. Ширина боковой навигации на десктопе при открытом Weekly Tracker приведена ближе к пропорциям эталона.

## Что специально НЕ менялось

- Состав и значения задач, включая legacy-записи и milestones.
- Нумерация проектных недель, первый день и текущая неделя, зависящие от реального начала проекта и его timezone.
- Быстрые статусы, создание задания по одной строке, права режима редактирования.
- IndexedDB/backup/import, Overview, Systems, Issue Tracker, Configuration Report, Collab Hub.
- Текущий Vercel-деплой не обновлялся: здесь только исходный ZIP.

Ограничение: `npm install` не завершился в среде сборки (пакеты недоступны), поэтому **полный `npm run build` и фактическое визуальное совпадение в браузере здесь не подтверждены**. Контрактные тесты не являются пиксельным screenshot-diff. Перед заменой production-кода рекомендуются install/build и браузерный просмотр на целевом разрешении.

## Обновление без потери данных

1. Сохранить backup на текущем сайте: **Overview → Demo data, backup & audit → Export project backup**.
2. Распаковать ZIP и установить пакеты (`npm install`); выполнить `npm test`, `npm run lint`, `npm run build`.
3. Выкладывать на тот же домен при необходимости сохранить имеющийся browser IndexedDB. Сам ZIP не удаляет браузерную базу, но смена origin/очистка данных браузера её не переносит.
4. Проверить четыре колонки и footer при закрытом и открытом боковом drawer, а также Project start / Today и мобильное представление.

Файл макета: `design_references/approved_weekly_tracker_light_accents.png`. Старые отчёты сохранены для истории; при расхождении визуальных требований приоритет имеет данный документ и утверждённый макет.
