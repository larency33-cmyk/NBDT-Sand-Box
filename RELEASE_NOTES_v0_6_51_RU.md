# NBDT v0.6.51 — фиксированные панели System Registry и Configuration Report

**Основа:** NBDT v0.6.50. Изменена прокрутка **только** двух главных разделов; данных и механизмов авторизации изменения не касаются.

## System Registry

- Название окна, экспорт/добавление системы, поиск, все фильтры и количество показанных систем остаются на месте.
- Ниже создана собственная область вертикальной прокрутки `nb51-registry-scroll` — все карточки систем доступны в непрерывной сетке (пагинация не возвращается).
- Область прокрутки доступна клавиатуре (`tabIndex=0`, роль `region`, название `Systems list`).
- Нативная полоса прокрутки визуально скрыта; мышь, тачпад, касания и клавиатура работают как прежде.

## Configuration Report

- Название, кнопки Export/Import, все четыре KPI, System readiness и управляющие вкладки, поиск и фильтры остаются на экране.
- Вертикально прокручивается только список систем внутри таблицы; заголовки колонок закреплены `position: sticky`.
- Таблица продолжает горизонтально прокручиваться при недостаточной ширине; полосы прокрутки скрыты.
- На узких экранах KPI занимают одну прокручиваемую по горизонтали строку, чтобы не вытеснить таблицу за пределы экрана.

## Технические изменения

- Добавлен изолированный стилевой файл `nbdt-layout-v051.css`, подключённый последним.
- System Registry: контейнер с отдельным скроллом в `index.tsx`. Configuration Report: использована существующая `nb-report-table` без изменения логики сортировки/фильтрации/редактирования.
- На двух указанных маршрутах отключён скролл наружного `<main>`; управление scrollTop остаётся у соответствующего вложенного контейнера.
- Версия `package.json`: `0.6.51`.

## Проверка

- **294/294 автоматических теста** успешно пройдены, включая три новые проверки структуры фиксированных панелей и внутренних прокруток.
- `node scripts/check-syntax.cjs` — ошибок нет.
- Chromium на синтетических страницах с теми же классами и финальными CSS-слоями: 1650×900 и 390×800. На обеих ширинах список/таблица прокручиваются, заголовок/фильтры остаются на месте, в отчёте заголовки колонок не движутся, а `main.scrollTop` остаётся нулём.
- **Ограничение:** визуальные тесты проводились на отдельных HTML-фикстурах, не на собранном приложении. Production build Vite и реальный деплой Vercel не подтверждены из-за отсутствия npm-зависимостей в среде.
