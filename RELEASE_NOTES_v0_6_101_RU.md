# NBDT v0.6.101 — финальная полировка экрана входа

Основа: загруженный пользователем полный проект v0.6.100.

- Оригинальный пользовательский PNG Royal Caribbean Group (Royal Caribbean International, Celebrity Cruises и Silversea) размещён внизу вместо набранного текста. Изображение оптимизировано без изменения пропорций; прозрачность сохранена.
- Стартовый экран распределяет доступную высоту между шапкой, главным блоком, сценой и нижним логотипом. SVG сцена сохраняет пропорции при уменьшении высоты; применяется отдельная мобильная вертикальная композиция. Элементы не должны уходить под нижний край типичных экранов.
- Пиксельные облака движутся только слева направо по бесшовному повторяемому треку, строго один повтор за 40 секунд.
- Индикаторы на серверных стойках имеют независимые по фазе мягкие мерцания и подсветку; все анимации подчиняются существующим паузе, настройке уменьшения движения и общей шкале времени.
- Дополнительные блики воды с мягким горизонтальным движением и затуханием (4 секунды, замкнутый цикл).
- Код SSO, доступы, состояние проекта, функциональные страницы и данные не менялись.

Примечание: первая кнопка SSO сохраняет поведение загруженной исходной версии, без подключения реального корпоративного провайдера.
