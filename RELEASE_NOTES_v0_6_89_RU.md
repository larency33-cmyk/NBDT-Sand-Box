# NBDT Hub v0.6.89 — вставка нескольких заданий из Excel в Weekly Tracker

## Что изменено

**Weekly Tracker → выбрать сотрудника и неделю → Add assignment**

- В существующей форме теперь можно вставить содержимое одной Excel-ячейки, где каждое задание начинается с маркера **•** (также поддерживаются ●, ▪, - и нумерация).
- Каждая строка с новым пунктом становится **отдельным заданием** в выбранной неделе и у выбранного сотрудника. Если пункт переносится на следующую строку без нового маркера, продолжение включается в это же задание.
- Для текста без маркеров каждая непустая строка считается отдельной задачей.
- Перед сохранением появляется компактный предпросмотр: количество распознанных заданий, первые 8 пунктов, сколько осталось.
- Кнопка меняется на **Add N tasks**. Список сохраняется **одной транзакцией** в проект (никаких частичных импортов при ошибках).
- Поддерживаются до **100 заданий за один раз**, длина названия каждого — до **160 символов**. Неверные данные не обрезаются и не добавляются.
- Старый сценарий не изменён: одно задание можно ввести вручную и сохранить клавишей **Enter** либо кнопкой **Add task**. Ctrl+Enter (Cmd+Enter) сохраняет список; Shift+Enter добавляет перенос строки.
- Импортированные задания создаются с теми же начальными значениями, что и обычные: **Planned**, продолжительность **1 неделя**, выбранный сотрудник и неделя. Отдельные задания по-прежнему можно редактировать, перемещать и удалять индивидуально.

## Важные ограничения

- Распознавание происходит из **текста буфера обмена**: загружать Excel-файл не нужно.
- Форматирование Excel, цвет ячейки, статус и даты соседних ячеек не переносятся. Импортируются только названия задач из скопированного текста.
- Разделы Assignment, Systems, Issues и Configuration Report не изменены.
- Уведомление после сохранения показывает количество добавленных заданий.

## Как проверить

1. Откройте Weekly Tracker, выберите неделю и сотрудника → Add assignment.
2. Вставьте несколько строк из Excel с маркерами **•**. Убедитесь, что предпросмотр показывает правильные названия и число заданий.
3. Нажмите **Add N tasks**: каждое должно появиться отдельно у выбранного сотрудника на нужной неделе.
4. Проверьте одно короткое задание через Enter — должен остаться старый сценарий.
5. Проверьте перенос длинного пункта, ошибки длины более 160 символов, и сброс/закрытие без сохранения.
