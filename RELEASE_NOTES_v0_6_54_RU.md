# NBDT v0.6.54 — Assignment usability и управление сотрудниками

Основа: **v0.6.53**. Данные 13 сотрудников и 108 исходных назначений сохранены; новая версия не сбрасывает IndexedDB. Изменения ограничены страницей Assignment и порядком боковой навигации.

## Assignment

1. Удалён фильтр **All positions** вместе с неиспользуемым состоянием фильтрации.
2. Поле поиска оставлено в одной рамке; вложенный `input` не рисует дополнительный бордер или системную фокусную рамку. Работа поиска по людям и системам сохранена.
3. В заголовке каждой колонки добавлен собственный небольшой карандаш **Edit team member**, доступный только Admin / Super Admin. Редактор изменяет полное имя, должность и дату присоединения. Идентификатор сотрудника остаётся тем же, его существующие назначения сохраняются; обновлённое имя Owner сразу используется остальными страницами при точном совпадении системы.
4. В самом конце таблицы добавлена колонка **Add person**, видимая в режиме Admin / Super Admin. Новому сотруднику задаются имя, должность и дата присоединения; пустая колонка становится полноценной и также доступна для добавления систем. Повторяющиеся имена и некорректные даты отклоняются.
5. Улучшен drag-and-drop: отдельная визуальная карточка с указанием исходного и целевого владельца, подсветка целевого столбца и конкретной ячейки, эффект появления после переноса. Можно отпускать карточку и в заголовке нужного сотрудника. Перенос использует прежний идентификатор назначения и сохранение через существующий `onChange`.
6. Высота таблицы подстраивается под окно: при свободном пространстве строки увеличиваются равномерно, при большом количестве назначений внутренняя вертикальная прокрутка остаётся доступной.
7. Внизу матрицы появилась **тонкая горизонтальная полоса прокрутки**, управляемая мышью, тачпадом и клавиатурой. Нативные полосы приложения глобально скрыты, поэтому полоса реализована как отдельный синхронизируемый элемент; закреплённая колонка Project остаётся слева.

## Навигация

- **Assignment** перенесён после **Configuration Report**.
- **Collab Hub** убран из бокового меню. Код страницы не удалён — это изменение только навигации.

## Данные и доступ

- Авторизация POC не менялась. Guest видит таблицу без редактирования; Admin / Super Admin получают дополнительные элементы редактирования.
- Новые и изменённые сотрудники сохраняются в прежнем ключе `nbdt_assignment_roster_v052` через существующую очередь IndexedDB. Не требуется миграция или очистка данных.
- Никакого нечёткого сопоставления имён систем нет. Для уже назначенных систем ссылки Owner продолжают разрешаться по точному полному названию; повторения сохраняют нескольких владельцев.
- Не добавлен серверный backend; разные браузеры не синхронизируют данные автоматически.

## Проверки

- **309 из 309** тестов пройдены, включая 7 новых проверок модели и интерфейсного контракта Assignment.
- TypeScript/TSX символы проверены `scripts/check-symbols.cjs` (7 TSX-файлов), новая страница успешно транслирована TypeScript без синтаксических диагностик.
- CSS-геометрия Assignment отдельно проверена в Chromium на ширинах 1650, 1280 и 390 px, включая таблицу шире viewport и заполнение высоты до 1440 px. Это **изолированный визуальный тест HTML/CSS**, а не полный запуск React-приложения.
- **Vite production build не выполнен**, поскольку npm-зависимости отсутствуют и registry недоступен (`EAI_AGAIN`). После публикации проверить статус Vercel и открыть как минимум Weekly Tracker, Assignment, System Registry и Configuration Report.
