# NBDT Hub v0.6.76 — гибкий импорт Lessons Learned из Excel

## Исправлено

- Урок из Excel теперь не обязан иметь ровно четыре столбца: поддерживаются три колонки (без Resolved By), стандартные четыре колонки и более четырёх, если экспорт разбил текст на дополнительные ячейки.
- В первую очередь используется HTML-таблица из буфера обмена Excel, чтобы не терять структуру при многострочном тексте. Если HTML-таблица недоступна, используется обычный текст TSV.
- Импорт распознаёт заголовки Lesson Learned, Issue Profile, Details / Corrective Action, Resolved By, а также подписи DESCRIPTION / APPLICATION / COMMENTS / CORRECTIVE ACTION в неоднородном тексте.
- Длинные фрагменты не отбрасываются: они собираются в соответствующих полях с сохранением переносов строк. Если разделить фрагменты однозначно нельзя, показывается предупреждение в Preview.
- При вставке только одного текстового блока не выдумывается название урока: текст переносится в обнаруженное поле, а название пользователь может вписать в Preview.
- Все четыре поля предварительного просмотра можно исправить до сохранения. «Save Lesson» доступен после указания названия урока и судна.
- Для защиты данных импорт по-прежнему обрабатывает только один урок за раз; отдельные уроки не склеиваются без подтверждения.
- Старые уроки, таблицы по судам, индивидуальное редактирование и импорт конфигурации из v0.6.75 сохранены.

## Как использовать

1. Открыть System Guide → Lessons Learned → карандаш.
2. Выбрать Vessel / project.
3. Скопировать один урок из Excel (включая три или четыре ячейки) и вставить Ctrl+V.
4. Проверить «Review detected fields», при необходимости исправить любую из четырёх колонок.
5. Нажать «Save Lesson».
