# NBDT Hub v0.6.78 — Current Ship Review в Lessons Learned

База обновления: v0.6.77. Внесены изменения непосредственно в System Guide.

## Что изменилось

- Добавлена пятая колонка `Current Ship Review` в таблице Lessons Learned. Первые четыре колонки (включая историческое `Resolved By`) сохранены без изменений.
- Статусы проверки урока для **текущего проекта**: `Pending review` (по умолчанию), `In progress`, `Confirmed`.
- Администратор может открыть `Update review`, изменить статус, вписать имя проверившего и комментарий, затем сохранить. Галочка рядом со статусом открывает форму подтверждения. Имя требуется для `In progress` и `Confirmed`. `Pending review` не требует имени.
- Для подтверждения сохраняется дата и время; при повторном открытии проверки статус меняется, старое подтверждение перестаёт считаться действующим.
- В заголовке Lessons Learned показывается число подтверждённых, проверяемых и ожидающих уроков.
- Проверка хранится как `currentShipReview` внутри существующего `lessonsLearnedItems` и автоматически сохраняется через существующий `onUpdateSystem`.
- Каждая проверка привязана к `project.id`. При копировании проекта уроки сохраняются, но их подтверждение для другого проекта **не переносится**.
- Старые Excel-уроки и флаг `checked` не преобразуются автоматически в подтверждённые: все непроверенные уроки текущего проекта начинаются с `Pending review`.
- Редактирование источника Lessons Learned и Excel-импорт остались доступными. Guests видят статусы, но не могут их менять.

## Обновление через GitHub

Распаковать `NBDT-078-GITHUB.zip` в корень репозитория поверх v0.6.77 с сохранением подпапок, зафиксировать изменения в GitHub и дождаться успешного деплоя Vercel. Бэкап текущих данных (IndexedDB) рекомендуется до обновления.

## Важная особенность POC

Проверивший указывается вручную. Имя и дата являются удобной историей действий в локальной POC-версии, **не серверной проверкой личности и не неизменяемым audit log**. Общая корпоративная синхронизация требует серверного хранилища.

## Проверки

- `npm test` — проверка всей существующей логики и новые тесты сохранения/смены статусов.
- `npm run check:syntax` и `node scripts/check-symbols.cjs` — предварительная проверка TSX.
- При отсутствии установленных npm-зависимостей полноценные `vite build`, `tsc --noEmit` и браузерный smoke-test не подтверждены.
