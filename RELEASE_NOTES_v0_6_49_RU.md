# NBDT v0.6.49 — заголовок Issues, модальное окно входа и Weekly Tracker

**Основа:** v0.6.48. Изменения относятся к интерфейсу. Формат данных, POC-аккаунты и механизм хранения не изменены.

## Что исправлено

1. **Issue Tracker — единая линия заголовков.** Левый отступ рабочей области задан тем же токеном `--nb46-workspace-inset: 15px`, что и на остальных трёх экранах. Убраны потенциальные дополнительный горизонтальный отступ/смещение вложенного блока `hero`. По вертикали заголовок использует 33 px на desktop (как Weekly Tracker) и 17 px на mobile.
2. **Sign in — корректное затемнение всего экрана.** Вместо вывода модального окна внутри прокручиваемого `<main>` окно авторизации рендерится через React `createPortal` непосредственно в `document.body`. Это исключает обрезание подложки контейнером страницы. Подложка фиксирована на всю ширину и высоту viewport (`100vw`, `100dvh`, `inset:0`), поверх бокового меню и остального контента, с сохранением закрытия по Escape / клику снаружи.
3. **Weekly Tracker — убраны две кнопки справа в шапке.** Удалены **Share view** и **Add task** именно из верхнего заголовка Weekly Tracker. Добавление и изменение заданий внутри назначений/контекстных действий сохранены; прямая навигация по неделям и выбранной неделе продолжает работать.

## Технические детали

- Новый финальный CSS-слой: `nbdt-layout-v049.css`, импортируется после v048.
- Изменения: `index.tsx`, `src/workspace.tsx`, `package.json`, новый CSS и тесты.
- Существующие разделы Systems, Configuration Report и Administration не перерабатывались.
- Авторизация остаётся **browser-local POC**, а не корпоративным backend. Для production нужна серверная проверка прав.

Для перехода с **v0.6.48** распаковать архив `NBDT_GitHub_Changed_Files_v0_6_49.zip` в корень репозитория, сохраняя структуру каталогов и заменяя изменённые файлы; убедиться, что GitHub/Vercel установил все зависимости.
