# NBDT v0.6.44 — удобный выбор Project start в Weekly Tracker

**Базовая версия:** v0.6.43. Новый релиз ограничен виджетом выбора даты начала проекта в разделе Weekly Tracker; существующие данные и другие разделы проекта не менялись.

## Что исправлено

1. **Отмена автосохранения на каждом движении календаря.** Стандартный HTML `<input type="date">` был связан с обработчиком изменения `onChange`, который немедленно запускал изменение даты проекта и браузерный диалог `window.confirm`. Поэтому навигация по месяцу или году непреднамеренно могла вызывать запрос OK. Вместо него внедрён собственный календарь с независимым черновиком выбранной даты.
2. **Свободная навигация по годам и месяцам.** По кнопке выбора даты открывается календарная панель с прямыми выпадающими списками месяца и года; отдельными кнопками переключения предыдущего/следующего месяца и года. Кнопка Today переносит выделение на текущий день проектного часового пояса, Saved date — к сохранённой дате.
3. **Одно осознанное подтверждение.** Клик по дню только изменяет предварительный выбор. Реальное сохранение `startDate` и перерасчёт календаря происходят только после **Apply date**. При неизменённой дате кнопка недоступна. **Cancel**, крестик, Escape и клик за пределами панели закрывают календарь без изменений.
4. **Предупреждение о последствиях без системного диалога.** Если в проекте есть задачи и пользователь выбирает другую дату, в панели отображается напоминание: положение задач по проектным неделям сохраняется, даты Milestones сдвигаются вместе со стартом, явно назначенные сроки задач не меняются. Дополнительного браузерного OK нет.
5. **Ошибки сохранения показываются внутри календаря.** При отклонении записи панель остаётся открытой и предварительно выбранная дата сохраняется для повторной попытки. Пока выполняется запись, подтверждение и элементы навигации блокируются.
6. **Стиль и адаптивность.** Компактная бело-голубая панель в общей палитре NBDT, неделя с понедельника, подсветка текущего и выбранного дня, фокус клавиатуры, закрытие по Escape. На узких или низких экранах панель центрируется, не обрезаясь экраном, с внутренней прокруткой при необходимости.
