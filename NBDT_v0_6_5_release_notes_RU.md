# NBDT v0.6.5 — утверждённый макет Weekly Tracker

## Основа

Проект **v0.6.4**. За основу взят предоставленный пользователем утверждённый скриншот от 22 октября 2026 года, добавленный как `design_references/approved_weekly_tracker_2026_10_22.png`.

## Сделано

- **Шапка таблицы**: над колонками остаются только milestone-плашки. Дублирующие названия недель и диапазоны дат сверху удалены; создание и редактирование milestone в Edit mode сохранено.
- **Нижние карточки**: вместо 11 компактных отдельных кнопок показаны **четыре широкие карточки**, по одной под каждой видимой колонкой с задачами. Карточки содержат `Week N`, точный период от даты начала проекта и все семь дней недели. Подложки тонко чередуются между колонками.
- **Согласованные размеры**: общая сетка 220 px для Employee + 4 равные части; при горизонтальной прокрутке на небольших экранах положение карточек синхронизировано с основной таблицей.
- **Текущий день**: дата определяется в часовом поясе проекта и пересчитывается раз в минуту, только реальный текущий день получает синюю выделенную плашку. Если он вне отображаемого периода, плашки нет. Если проект начинается, например, в субботу, семь подписей идут Sat, Sun, Mon ... Fri — даты не подгоняются под календарный понедельник.
- **Текущая неделя**: сохраняется акцент колонки и выбранной недели; кнопки перехода назад, вперёд и Today сохранены.
- **Правый drawer**: из предыдущей версии v0.6.4 по-прежнему появляется поверх матрицы и не сжимает её; быстрые статусы и `+ Add assignment` не менялись.

## Важные замечания

- В образце приведены иллюстративные имена и даты. В приложении **не создавались дополнительные демоданные**: всё вычисляется из текущих задач и `project.startDate`.
- Навигация сохраняет проектную нумерацию Week 1, Week 2 и далее; верхней формы Week нет.
- Предоставленный макет — визуальное направление; точное пиксельное совпадение в Chromium **не утверждается**, потому что среда не позволила загрузить npm-зависимости для запуска полноценной сборки.

## Проверки на этой версии

- `npm test`: **99/99 PASS**, включая 6 новых проверок карточек, календарных дней, выравнивания, синхронизации и drawer.
- `node scripts/check-syntax.cjs`: 0 ошибок TS/TSX.
- `node scripts/check-bindings.cjs`: 0 неразрешённых идентификаторов в проверяемой области, но 16 неустановленных внешних модулей.
- `npm run build`, браузерная регрессия — **не выполнены** (не завершилась установка npm-пакетов; Vite не установлен в этой среде).

## Установка

1. Сделать резервную копию проекта через **Overview → Demo data, backup & audit → Export project backup**. IndexedDB хранит данные в конкретном браузере и origin.
2. Распаковать ZIP в отдельную папку и запустить `START_WINDOWS.cmd`, либо `npm install` / `npm run dev` на машине с Node.js 22.12+.
3. Перед публикацией на Vercel выполнить `npm run lint`, `npm run build`, проверить Overview, List, горизонтальную прокрутку, выбор задачи и drawer в браузере.
4. Если текущие данные важны, оставаться на том же Vercel-origin и предварительно иметь резервную копию; новый домен автоматически не переносит IndexedDB.
