# NBDT Hub v0.6.74 — Lessons Learned / Excel import

## Что изменено

1. **Guide → Lessons Learned** остаётся в существующей оранжевой рамке с прежним заголовком и карандашом.
2. Каждый урок показывается в четырёх столбцах, как в Excel:
   `Lesson Learned | Issue Profile | Details / Corrective Action | Resolved By`.
   Содержимое многострочных ячеек, переносы строк и подписи типа COMMENTS и CORRECTIVE ACTION сохранены.
3. Уроки разделены по судам (например, `Legend of the Seas`, `Star of the Seas`). В группе указан счётчик уроков. Названия судов можно вводить произвольно.
4. **Администратор:** раскрыть Lessons Learned → нажать карандаш → выбрать судно → скопировать ровно четыре ячейки одного урока из Excel → Ctrl+V в поле Paste from Excel → проверить Preview → `Save Lesson`.
   Сначала считывается HTML-таблица из буфера обмена, при недоступности — текст с табуляцией и экранированными многострочными ячейками.
5. Редактор позволяет создавать, изменять и удалять отдельные уроки. Удаление требует подтверждения. Подозрительные дубликаты одного урока на одном судне не добавляются.
6. Старые уроки с полем `text` автоматически отображаются без удаления данных в группе `Vessel not specified`, пока им не назначат судно. Старый флаг `checked` сохраняется в хранилище, но статус не показывается.
7. **Без дополнительных статусов, поиска и фильтров.** Цветная акцентная зона — оранжевая рамка, а заголовки судов и колонок спокойного голубого цвета.

## Важное ограничение POC

Данные Lessons Learned сохраняются через **существующий механизм сохранения NBDT** (IndexedDB браузера), а не в центральной базе AWS. Для общего доступа между пользователями потребуется запланированное подключение backend/API и базы данных.
