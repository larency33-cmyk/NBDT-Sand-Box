# NBDT Hub v0.6.117 — улучшенная читаемость Assignment и точная подсказка Drag & Drop

Основа: v0.6.116, утверждённый стиль Assignment.

- Верхние карточки сотрудников получили мягкие скругления: `12px 12px 10px 10px`. Ширина колонок, размер кружков с инициалами (**28×28px**) и размер букв (**13px**) не изменены.
- Названия назначений увеличены на **25%**, с **10px до 12.5px**, при сохранении обычной толщины шрифта `400` и приглушённого серо-синего цвета `#52627d`. Размер шрифта в других разделах не меняется.
- Фон пустых ячеек осветлён на **30% к белому**: `#f1f5fb → #f5f8fc`. Пустые ячейки остаются интерактивными: при наведении по-прежнему доступна команда добавления назначения.
- Перемещение задания теперь показывает **яркую синюю линию с круглым маркером** на границе точной позиции вставки. Индикатор использует фактическую семантику `moveAssignment`: при переносе вверх линия перед выбранной карточкой, при переносе вниз в той же колонке — после выбранной; для другой колонки, заголовка и свободного места вставка рассчитывается по существующим данным. В случае отсутствия изменений индикатор не показывается.
- Старые методы изменения порядка, сохранения данных, прав доступа, редактирования, перестановки колонок и навигации по одной колонке оставлены без изменений.
- Изменения ограничены страницей Assignment и её CSS, отдельным тестом и документацией.

Проверки: 14/14 профильных тестов; в полном наборе 640 успешных из 663, 23 существовавших ранее падения совпали с v0.6.116. Syntax check прошёл. Изолированный UI-образец проверен в Chromium при 1734×862, 1366×768 и 900×700: размеры инициалов 28×28px, строк 49px (на измеренных строках), шрифт 12.5px, скругление 12/10px; линия вставки проверена для before/after. **Полная Vite-сборка не подтверждена**: `vite: not found` (нет установленных npm-зависимостей). Это не production smoke test.
