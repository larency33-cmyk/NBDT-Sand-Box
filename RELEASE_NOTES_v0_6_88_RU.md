# NBDT Hub v0.6.88 — более заметная кнопка Documentation в Configuration Guide

## Обновление

- Только **внутри System Configuration Guide** кнопка Documentation получила понятную иконку документа (FileText) и маленькую иконку внешней ссылки (ExternalLink).
- Кнопка теперь с насыщенным синим фоном, белыми надписью и иконками, мягкой тенью, аккуратным hover и видимым focus для клавиатуры.
- Ссылка по-прежнему ведёт на тот же сохранённый адрес, открывается в новой вкладке через target="_blank" с rel="noopener noreferrer".
- Если у системы нет корректного Documentation URL, кнопка, как и прежде, не появляется.
- **Внешняя** Documentation на карточках **System Registry** не изменена.
- Back to systems, Import from Excel и остальные элементы Guide остались без изменений.

## Проверка

1. Открыть System Registry → Open guide у системы со ссылкой на документацию.
2. Проверить новую синюю кнопку Documentation с иконками, наведение и открытие документа в новой вкладке.
3. Вернуться в System Registry и проверить, что внешний Documentation выглядит по-старому.
4. Проверить Guide у системы без документации: кнопка не должна появляться.
5. Убедиться, что Back to systems работает, в том числе на узком экране.

Добавлены регрессионные проверки `tests/guide-documentation-v088.test.mjs`. Полный production-build и браузерная проверка без CI в этом запуске не подтверждаются.
