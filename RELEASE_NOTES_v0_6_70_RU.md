# NBDT v0.6.70 — пять оттенков воды и независимая анимация круговых KPI

Базовая версия: **v0.6.69**.

## Что изменено

- В четырёх KPI на Overview (Base Configuration, Ready for Deployment, Deployed, Cyber Approved) вода теперь имеет **пять отдельных оттенков соответствующей цветовой темы**. Помимо пяти цветовых слоёв добавлен плавный SVG-градиент, проходящий все пять оттенков даже при небольшом заполнении круга (например, 12%).
- Вместо прежних шести пузырьков добавлено **по девять пузырьков**, размеры и места появления различаются. У каждого пузырька собственное смещение времени и скорость, они плавно всплывают.
- У **каждого KPI свой стиль анимации**: отдельное движение общего уровня жидкости, разная скорость и направление передней и задней волн, собственные задержки пузырьков. Четыре кружка больше не двигаются синхронно.
- Исправлен конфликт CSS-трансформаций: процент заполнения задаётся внешним SVG-контейнером и не сбрасывается из-за анимации внутренних волн.
- Плоский дизайн сохранён. Внешняя дуга прогресса по-прежнему отрисовывается одним чётким SVG-контуром с корректным значением процента.
- Учитывается системная настройка `prefers-reduced-motion`: для пользователей с ограничением движения анимации отключаются.

## Изменённые файлы

- `src/workspace.tsx` — пять оттенков, многослойная жидкость, девять пузырьков и отдельная позиция уровня жидкости.
- `nbdt-overview-v070.css` — независимые анимационные профили, движение волн и пузырьков.
- `index.tsx` — подключение CSS после `nbdt-overview-v069.css`.
- `package.json` — версия 0.6.70.
- `tests/overview-liquid-v069.test.mjs` и `tests/overview-liquid-v070.test.mjs` — регрессионные проверки.
- `README.md`, этот файл, манифест и changelog.

## Проверки

- **365 автоматических тестов пройдены** (`npm test`).
- `node scripts/check-symbols.cjs` — успешно.
- `node scripts/check-syntax.cjs` — успешно.
- Синтаксис `src/workspace.tsx` проверен через TypeScript transpilation.
- Полная production-сборка Vite пока не подтверждена: в текущем контейнере отсутствуют `node_modules` проекта.

## Установка

Для обновления существующей v0.6.69 загрузите в GitHub файлы из архива **NBDT-070-GITHUB.zip**, сохраняя структуру папок. ZIP `NBDT-070-FULL.zip` содержит весь исходный проект. Обратите внимание: для корпоративного развёртывания нужно отдельно провести production build и browser smoke test в CI.
