# NBDT Hub v0.6.79 — оформление Lessons Learned как в утверждённом макете

## Что изменилось

- Сохранены оранжевая внешняя рамка и светлая цветовая тема NBDT. Заголовок стал выразительнее и показывает число уроков, Confirmed, Pending и In progress — с разделителем как на макете.
- У каждой группы судна — широкая приглушённо-голубая шапка и счётчик уроков. В таблице **ровно пять колонок**: Lesson Learned, Issue Profile, Details / Corrective Action, Resolved By, Current Ship Review.
- Колонка Current Ship Review оформлена как на эталоне: крупный квадратный чекбокс, пастельные цветные таблетки Pending review / In progress / Confirmed, имя и дата проверки, заметка. При отсутствии проверки видно «Not yet reviewed for this ship.»
- Для изменения статуса администратор нажимает на чекбокс или на саму цветную плашку; открывается прежний редактор со статусом, проверившим и примечанием. Отдельная кнопка редактирования не загромождает таблицу: для открытия редактора достаточно нажать на саму плашку статуса.
- Заголовки, шрифты, отступы и ширины колонок приведены ближе к утверждённому макету. На узких экранах таблица прокручивается горизонтально, чтобы не искажать содержание.

## Данные и поведение

Изменения **только визуальные**: существующие три статуса, их запись по project ID, права администратора, история уроков и импорт из Excel остаются прежними. Примеры в макете не записываются в проект.

## Файлы

- `src/lessons-learned-section.tsx` — разметка статусов, подписей и управления, 5-колоночная таблица;
- `src/workspace.tsx` — заголовок и счётчики статусов;
- `nbdt-lessons-v079.css` — новая цветовая схема/геометрия макета;
- `index.tsx` — подключение CSS после v078;
- `package.json`, `README.md` и этот релизный документ;
- `tests/lessons-review-layout-v079.test.mjs` — визуальные контракты.

## Проверка

Проект запускает исходные автоматические тесты, тесты макета и синтаксическую проверку. Полная Vite/Chromium smoke-сборка требует установленных npm-зависимостей и должна выполняться в GitHub Actions/Vercel. Версия базы и проектных данных не меняется.
